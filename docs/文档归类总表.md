## 9. 归类原则

1. 项目开发只放现在要看、要验收、要部署的文档。
2. 当前需求只放当前有效范围和主 PRD。
3. 方案设计只放当前有效方案、后续方案和已废弃方案。
4. `项目开发` 只放过程、现状、问题、联调、会议和历史归档。
5. 规范只放长期规则。
6. 排期、日报、脚本材料、图片证据各自独立，不混到需求里。
