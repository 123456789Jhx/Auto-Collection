## 5. 当前业务边界

1. 当前主链路是 Android 手机脚本采集公开可见农业视频/直播信息，并把设备状态、心跳、日志、采集记录同步到后台。
2. 后台当前主定位是轻量监控、配置和排障平台；“智能发布视频”板块只覆盖视频上传、OSS 存储、发布任务和 App 自动发布闭环。
3. 远程控制采用“后台记录命令，手机 Agent 主动拉取执行”的方式，不直接公网暴露 ADB。
4. 直播评论能力按授权场景执行：默认真实发送关闭；指定直播间测试必须显式配置目标直播间、打开 `allowRealSend`、受发送条数和发送间隔限制，并保留审计记录。
5. 不绕过验证码、登录校验或平台风控，不采集非公开内容，不承诺平台账号标签或推荐结果。

## 6. 清理规则

1. 方案设计统一进入 `方案设计/`，按架构、功能、后续扩展分类。
2. `当前需求/` 只放当前范围口径，不再放具体设计方案。
3. `项目记录/` 只放过程、会议、联调、证据、卡点、历史归档，不再放当前有效方案。
4. 运行日志、临时错误输出、一次性调试输出不放入 `docs`。
5. 真机截图、录屏、XML 证据可以保留，但必须有对应 Markdown 记录说明来源、时间、验证结论和用途。
