## 4. 归档位置

1. 历史需求和旧稿放 `项目开发/` 下的过程目录。
2. 会议原文放 `项目开发/会议原始记录/`。
3. 设备联调过程放 `项目开发/设备与联调记录/`。
4. 旧脚本材料放 `历史脚本材料/`。
5. 直播互动旧稿说明放 `项目开发/直播互动旧稿归档/`。

## 5. 当前业务边界

1. 后台当前是监控、配置、排障和审计平台。
2. 直播评论默认不做真实发送扩展。
3. 设备认证以唯一设备身份和 token 绑定为准。
4. 不绕过验证码、登录校验或平台风控。
