# 项目现状

更新时间：2026-06-23

## 1. 当前阶段

Auto Collection 当前处于测试联调阶段，主线是：

1. 手机 Agent 常驻运行。
2. 后台集中查看设备、任务、心跳、日志和采集记录。
3. 后台下发命令，手机 Agent 主动拉取并执行。
4. 直播评论已进入指定直播间真机测试阶段。
5. 智能发布视频仍处于方案和一周排期阶段，未完成真机发布闭环。

| 模块 | 当前状态 |

| 智能发布视频 | 已有方案和排期，待开发闭环 |

## 4. 当前边界

1. 不接入抖音官方 API。
2. 不绕过验证码、登录校验或平台风控。
3. 不采集非公开内容。
4. 不默认开启点赞、关注、私信等真实互动。
5. 直播评论真实发送必须有指定直播间、显式开关、发送限制和审计记录。
6. 智能发布视频本周目标是最小闭环，不包含多平台、复杂排期和发布后数据分析。
