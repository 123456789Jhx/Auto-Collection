## 3. 回归清单

1. 后台下发直播评论 `START`，手机自动进入指定直播间。
2. 打开 `allowRealSend` 后，评论发送受条数和间隔限制。
3. 后台能看到 `planned`、`sent`、`failed`、`skipped` 记录。
4. 后台下发 `STOP` 后，直播评论子任务停止，Agent 保持常驻。
5. 手机端重新启动后能注册、拉取配置、上传心跳。
6. 生产环境 `/ready` 正常，后台页面和 API 版本一致。

## 4. 证据要求

1. Bug 修复必须对应截图、日志、命令 ID 或测试结论。
2. 真机截图放入 `docs/截图证据/`。
3. 演示录屏放入 `docs/演示录屏/`。
4. 临时 `.tmp/`、根目录临时截图不作为正式证据。
