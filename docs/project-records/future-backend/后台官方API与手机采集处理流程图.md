# 后台官方 API 与手机采集处理流程图

## 1. 流程说明

该流程描述后台如何同时接入官方开放 API 和手机自动化脚本上报数据，并统一进入候选视频、去重、AI 分析、人工审核、素材库和农业知识库。

外部采集结果进入素材获取环节，为后续对标拆解、选题文案、生产路径、拍摄脚本、素材匹配、剪辑草稿、发布计划提供素材输入。

## 2. Mermaid 流程图

```mermaid
flowchart TD
    A[创建农业采集任务] --> B{选择数据来源}

    B -- 官方 API --> C[官方 API 拉取任务]
    C --> C1[按关键词调用抖音开放 API]
    C1 --> C2[解析官方返回字段]
    C2 --> C3[写入原始 payload]
    C3 --> D[生成候选视频记录]

    B -- 手机自动化 --> E[下发任务给手机设备]
    E --> E1[手机刷视频并上传采集结果]
    E1 --> E2[接收 OCR/字幕/评论/截图]
    E2 --> E3[写入采集证据]
    E3 --> D

    B -- 混合来源 --> C
    B -- 混合来源 --> E

    D --> F[计算去重键]
    F --> G{是否已有候选}
    G -- 否 --> H[新增 video_candidate]
    G -- 是 --> I[合并来源和证据]
    I --> I1[更新 source_type = mixed]
    I1 --> J[进入待分析队列]
    H --> J

    J --> K[文本清洗]
    K --> L[农业相关性判断]
    L --> M{是否农业相关}
    M -- 否 --> M1[标记 rejected: 非农业相关]
    M1 --> END1[结束]

    M -- 是 --> N[标签抽取]
    N --> N1[作物/病虫害/农资/地区/季节]
    N1 --> O[知识点抽取]
    O --> P[广告营销和风险判断]
    P --> Q[质量评分]
    Q --> R[写入 video_analysis_result]
    R --> S[进入人工审核]

    S --> T{审核动作}
    T -- 通过 --> U[生成素材资产 material_asset]
    U --> U1[进入素材获取节点]
    U1 --> U2[供视频任务引用]

    T -- 通过为知识 --> V[生成农业知识点 knowledge_item]
    V --> V1[进入农业知识库]

    T -- 修改 --> W[修正标签/知识点]
    W --> R

    T -- 重新分析 --> X[重新进入 AI 分析队列]
    X --> K

    T -- 合并 --> Y[合并到已有候选或素材]
    Y --> END2[结束]

    T -- 驳回 --> Z[记录审核原因]
    Z --> END3[结束]
```

## 3. 关键数据流

| 来源 | 入库对象 | 后续处理 |
|---|---|---|
| 官方 API | `video_candidate.raw_payload` | 去重、AI 分析、审核 |
| 手机 OCR | `video_capture_evidence.content_text` | 文本清洗、知识抽取 |
| 手机截图 | `video_capture_evidence.file_url` | 审核证据 |
| 手机评论 | `video_candidate.hot_comments_json` | 热点观点和用户问题分析 |
| AI 结果 | `video_analysis_result` | 审核、入素材库、入知识库 |
| 审核结果 | `review_record` | 审计和版本追溯 |

## 4. 与视频生产流程的关系

```mermaid
flowchart LR
    A[项目/账号定位] --> B[素材获取]
    B --> C[对标拆解]
    C --> D[选题文案]
    D --> E[生产路径]
    E --> F[拍摄脚本]
    F --> G[素材匹配]
    G --> H[剪辑草稿]
    H --> I[发布计划]

    X[官方 API 采集] --> B
    Y[手机自动化采集] --> B
    Z[农业知识库] --> C
    Z --> D
```

说明：

1. 定位来自项目/账号层，不在单条视频采集时重新生成。
2. 外部采集只进入素材获取，不替代对标拆解、选题文案和后续生产流程。
3. AI 生成的标签、知识点和评分必须支持人工修改、通过、驳回和重新分析。

## 5. 验证点

1. 官方 API 和手机端数据都能写入统一候选视频模型。
2. 同一视频多来源采集后能合并为一条候选，保留多来源证据。
3. AI 分析结果与原始证据可追溯。
4. 审核通过后才能进入素材库或农业知识库。
5. 外部采集不会直接生成发布计划，不绕过原有视频任务生命周期。
