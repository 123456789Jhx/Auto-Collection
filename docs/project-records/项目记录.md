## 农业内容识别与搜索流

脚本不再只依赖推荐流随机刷内容，而是优先使用农业搜索关键词进入更稳定的农业相关视频流。关键词包括水稻病虫害、玉米病虫害、大棚蔬菜、果树修剪、农业种植技术等。进入搜索结果后点击第一个视频，再沿视频流继续浏览。

匹配逻辑仍以关键词规则为主，先快速读取可见文本，再根据农业关键词、营销词和低优先级词判断是否停留采集。该阶段的目标是减少无关视频停留时间，而不是做完整语义识别。

主要改动文件：

| 文件 | 更新内容 |
|---|---|
| `mobile-agent/autojs/config.js` | 增加 `task.keywords` 和 `match.agricultureKeywords` |
| `mobile-agent/autojs/platforms/douyin.js` | 增加搜索入口、搜索词输入、搜索结果视频点击逻辑 |
| `mobile-agent/autojs/core/matcher.js` | 负责农业关键词命中、营销词和低优先级词判断 |

## 视频与直播阶段

视频阶段使用 120-180 分钟随机时长，直播阶段使用 60-120 分钟随机时长。直播不再通过搜索框查找直播间，避免触发验证码，而是沿推荐流识别直播入口，限制单阶段进入直播间数量不超过配置上限。

直播停留时间按候选质量区分：低质量直播短停留，普通直播中等停留，高质量农业直播长停留。直播阶段结束后脚本应回到主流程，避免视频阶段结束后无法进入直播阶段。

主要改动文件：

| 文件 | 更新内容 |
|---|---|
| `mobile-agent/autojs/config.js` | 增加视频/直播随机时长、直播间数量和停留时间配置 |
| `mobile-agent/autojs/app/phase-runner.js` | 管理视频阶段、直播阶段、阶段结束和心跳上报 |
| `mobile-agent/autojs/domain/live-scorer.js` | 根据直播文本、农业词和观看信息评估直播候选 |
| `mobile-agent/autojs/platforms/douyin.js` | 负责直播入口识别、进入直播间、退出直播间和直播上下文恢复 |

## 风控与异常恢复

脚本增加风险词检测，包括验证码、安全验证、滑块、账号异常、访问频繁等。检测到风险后停止自动操作，并通过日志和心跳上报后台。页面进入评论、商品、个人页等非视频流场景时，脚本先尝试返回推荐流；恢复次数超过阈值后停止当前任务。

## 启动性能优化

此前脚本启动时会先执行后台日志上报和缓存补传，后台不可达或网络慢时会导致悬浮看板迟迟不出现。现在改为先创建悬浮看板，再通过后台线程上报启动日志和补传缓存。等待点击开始、运行中控制轮询也改为异步，避免后台接口卡住打开抖音或刷视频主流程。

抖音启动和搜索阶段的固定等待时间也进行了压缩，悬浮窗会显示当前阶段，例如“等待开始”“启动任务”“打开抖音”“搜索关键词”“进入搜索视频”，方便判断卡点。

主要改动文件：

| 文件 | 更新内容 |
|---|---|
| `mobile-agent/autojs/app/collector-app.js` | 看板优先创建；启动日志、缓存补传、即时心跳后台执行；增加阶段提示 |
| `mobile-agent/autojs/app/control-loop.js` | 控制命令轮询改为异步线程 |

## 远程 Agent 规划

基于后续手机分布全国运行、无法物理连接电脑维护的场景，新增远程手机 Agent 方案。方案明确手机脚本应长期常驻，采集任务结束后回到 `idle`，后台通过公网 HTTPS 接收心跳、下发命令、管理配置和发布版本。

该方案不是一次性落地，建议按常驻 Agent、实时心跳、远程控制、配置下发、版本检查、远程更新和告警分阶段实施。
