## 3. 对当前脚本的影响

该页面属于启动抖音后的干扰页，不属于采集目标页面。

处理策略：

1. 启动抖音后检测 `玩转抖音星卡`。
2. 检测到后执行 `back()` 返回首页。
3. 返回后继续检测 `首页` 或搜索入口。

已同步到：

```text

```
