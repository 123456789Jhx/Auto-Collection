# Android 构建环境安装记录

## 安装目标

为手机端 APK 封装和真机调试准备 Android 命令行构建环境。环境安装在 D 盘，避免工具分散到项目目录或系统目录。

## 安装目录

```text
D:\DevTools
├─ Downloads
│  └─ commandlinetools-win-latest.zip
└─ Android
   └─ Sdk
      ├─ cmdline-tools
      │  └─ latest
      ├─ platform-tools
      ├─ build-tools
      │  └─ 35.0.0
      ├─ platforms
      │  └─ android-35
      └─ licenses
```

## 环境变量

用户级环境变量：

```text
ANDROID_HOME=D:\DevTools\Android\Sdk
ANDROID_SDK_ROOT=D:\DevTools\Android\Sdk
```

用户级 `Path` 已追加：

```text
D:\DevTools\Android\Sdk\platform-tools
D:\DevTools\Android\Sdk\cmdline-tools\latest\bin
D:\DevTools\Android\Sdk\build-tools\35.0.0
```

## 已安装组件

```text
platform-tools       37.0.0
build-tools;35.0.0   35.0.0

```

## 验证命令

新开 PowerShell 后执行：

```powershell
adb version
sdkmanager --list_installed
aapt2 version
apksigner version
```

当前验证结果：

```text
adb: Android Debug Bridge 1.0.41, Version 37.0.0
aapt2: 0.9
apksigner: Android Asset Packaging Tool 2.19-11948202
```

## 后续使用

1. 手机打开开发者选项和 USB 调试。
2. 数据线连接电脑。
3. 执行：

```powershell
adb devices
```

4. 手机弹窗选择允许调试。
5. 电脑侧看到设备号后即可安装 APK 或抓取 logcat。
