### 10.3 最近定位并修复的问题

| 问题 | 根因 | 已做修复 |
|---|---|---|
| 采集记录日期详情接口 500 | Drizzle/Postgres 查询里用 raw SQL 绑定 `Date` 对象，postgres-js 报错：`The "string" argument must be of type string... Received an instance of Date`。 | `record.repository.ts` 和 `log.repository.ts` 把 `createdTo` 条件从 raw SQL 改为 `lt(...)`。 |
| 抖音输入关键词后没有进入农业搜索结果，脚本停掉 | 搜索提交后停留在搜索建议页，旧逻辑严格判断“不是搜索结果页”就失败；同时悬浮窗避让位置曾可能不可靠。 | `douyin.js` 增加搜索提交、点击第一条搜索建议、确认进入搜索结果页；搜索结果页进不去视频时停止并记录明确原因，不再退回推荐流。 |
| 搜索失败后可能刷推荐视频 | 旧逻辑在搜索结果页找不到可点击视频时会 `back()` 后继续 `nextVideo()`。 | 改为抛出 `search result video entry failed`，任务停止并上报原因，避免采集非农业推荐视频。 |
| 悬浮看板可能挡住关键点击区域 | 旧避让使用 `device.height - 240`，在部分环境日志里出现异常位置。 | `floaty-control.js` 改为移动到右上安全区域：`x = device.width - 140`，`y = 120`。 |
