# 方案设计索引

本文档是当前方案设计的唯一索引。方案按“架构方案、功能方案、后续方案”归类，避免和项目记录混在一起。

## 1. 架构方案

| 文档 | 当前状态 | 用途 |
|---|---|---|
| `架构方案/后台监控架构方案.md` | 当前有效 | 定义后台 API、数据库、页面、监控和移动端接口 |
| `架构方案/手机自动化脚本架构方案.md` | 当前有效 | 定义手机 AutoX.js 脚本、屏幕识别、采集流程和异常处理 |
| `架构方案/手机Agent脚本ZIP自动更新方案.md` | 部分有效 | 定义 Agent ZIP 更新目标；自动替换和回滚仍需继续验证 |

## 2. 功能方案

| 文档 | 当前状态 | 用途 |
|---|---|---|
| `功能方案/直播评论自动化方案.md` | 当前有效 | 定义后台配置、手机 Agent 进入指定直播间、计划和真实发送边界 |
| `功能方案/直播互动阶段边界方案.md` | 当前有效 | 定义 P0-P3 阶段边界、风控、审计和不做事项 |
| `功能方案/直播视频脚本功能拆分方案.md` | 当前有效 | 将视频采集、短视频发布、直播辅助拆成三条功能线 |
| `功能方案/智能发布视频后台方案.md` | 规划有效 | 定义视频上传、OSS、发布任务和 App 发布回传 |

## 3. 后续方案

| 文档 | 当前状态 | 用途 |
|---|---|---|
| `后续方案/后台官方API与手机采集接入方案.md` | 后续扩展 | 官方 API、AI 分析、素材库、知识库等方向，不作为当前验收承诺 |

## 4. 不放在这里的内容

1. 会议原文放在 `docs/项目记录/会议原始记录/`。
2. 真机联调过程放在 `docs/项目记录/设备与联调记录/`。
3. 项目现状放在 `docs/项目记录/项目现状.md`。
4. 项目卡点和问题 放在 `docs/项目记录/卡点与问题记录.md`。
5. 旧需求和阶段性旧稿放在 `docs/项目记录/历史需求归档/` 或 `docs/项目记录/直播互动旧稿归档/`。
6. 验收、部署、项目概览放在 `docs/当前入口/`。
