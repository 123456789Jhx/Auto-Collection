# 视频与直播采集方案

本文记录当前已做过的视频采集和普通直播采集功能，合并原直播视频脚本功能拆分方案中已经落地或仍适用的部分。短视频发布、发布后数据采集和智能发布后台不属于当前功能。

## 1. 功能定位

视频与直播采集用于让手机 Agent 在抖音公开页面中观察农业相关内容，记录候选内容、命中关键词、停留状态和运行日志。

当前重点是采集、观察和上报，不做发布、不做私信、不绕过平台限制。

## 2. 视频采集

视频任务目标：

1. 打开抖音视频播放上下文。
2. 按配置关键词和匹配词判断农业相关性。
3. 采集标题、作者、屏幕文本、热门评论或可见评论摘要。
4. 上报 `collection_records`。
5. 定期上报心跳、进度和运行日志。
6. 在达到时长、数量、停止命令或任务切换时安全退出。

核心流程：

```text
拉取配置
-> 恢复到视频播放上下文
-> 读取当前屏幕文本
-> 判断农业相关性
-> 采集候选记录
-> 上报结果
-> 滑动下一条
-> 检查停止、暂停或任务切换
```

## 3. 视频任务配置

| 字段 | 说明 |
|---|---|
| `searchKeywords` | 搜索或初始发现关键词 |
| `matchKeywords` | 农业相关性匹配词 |
| `videoMinutesMin` / `videoMinutesMax` | 视频任务时长范围 |
| `collectComments` | 是否采集公开可见评论 |
| `commentLimit` | 评论采集上限 |
| `heartbeatMinutes` | 心跳上报间隔 |

设备级配置可以覆盖公共任务模板。

## 4. 视频采集记录

记录写入 `collection_records`，重点字段包括：

| 字段 | 含义 |
|---|---|
| `sceneType` | 视频或直播 |
| `keyword` | 当前搜索或匹配关键词 |
| `matchedKeywords` | 命中的农业关键词 |
| `authorName` | 作者或账号名 |
| `titleText` | 标题或页面主文本 |
| `screenText` | 屏幕文本摘要 |
| `capturedAt` | 采集时间 |
| `rawPayload` | 原始补充信息 |

## 5. 普通直播采集

普通直播任务目标：

1. 在公开页面发现直播入口。
2. 进入直播间后停留观察。
3. 采样直播间标题、主播、画面文字和公开评论。
4. 判断农业相关性或直播候选价值。
5. 上报采集记录、心跳和运行日志。
6. 遇到风控、登录异常、验证码、未知弹窗时停止自动动作并上报。

普通直播采集不等同于直播评论。普通直播只观察和采集，不执行真实评论发送。

## 6. 直播候选判断

直播候选判断可以参考：

1. 标题是否包含农货、种植、养殖、农产品、产地、采摘等关键词。
2. 主播或账号名是否与农业相关。
3. 画面 OCR 或可见文本是否包含农业词。
4. 评论区公开文本是否出现农产品咨询、购买、产地、价格、规格等内容。
5. 风险词、验证码、登录提示、异常页优先判定为不可继续。

## 7. 任务状态

视频和直播任务需要持续上报：

| 状态 | 含义 |
|---|---|
| `idle` | Agent 待命 |
| `running` | 当前任务运行中 |
| `paused` | 后台暂停 |
| `stopped` | 后台停止或任务完成 |
| `error` | 任务异常 |

心跳中应带上当前任务、已运行时长、剩余时长、已采集数量、最近失败原因和当前页面上下文。

## 8. 任务切换要求

视频和直播任务必须服从后台任务切换：

1. 后台切到直播评论时，视频/直播任务要安全中断。
2. 中断前不要继续滑动或进入新直播间。
3. 中断原因上报 `task_switched`。
4. 新任务由手机端调度器和恢复层接管。
5. 直播评论结束后，如后台重新分配视频或直播，任务应从标准上下文恢复。

## 9. 风控和异常边界

遇到以下状态时，不继续自动操作：

1. 验证码。
2. 登录异常。
3. 账号风控提示。
4. 青少年模式等强阻断弹窗。
5. 无法关闭的未知浮层。
6. 网络异常多次重试失败。

处理方式：

```text
停止当前任务
-> 上报 failureReason
-> 保留页面样本或截图日志
-> Agent 回到待命或等待后台处理
```

## 10. 当前不做

1. 不做短视频自动发布。
2. 不做发布后数据采集。
3. 不做私信、关注、点赞等真实互动。
4. 不接入抖音官方 API。
5. 不把普通直播采集和直播评论混成同一任务。

## 11. 验收口径

1. 视频任务能运行、上报心跳、采集记录和日志。
2. 普通直播任务能进入直播间、停留采样并上报记录。
3. 后台能区分视频、直播、直播评论任务状态。
4. 后台 STOP 或任务切换后，视频/直播任务不会继续滑动或进入新直播间。
5. 风控、验证码、网络异常有明确失败原因。
