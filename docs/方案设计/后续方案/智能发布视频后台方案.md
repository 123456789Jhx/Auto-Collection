# 智能发布视频后台方案

## 1. 文档目标

本文保留为后续扩展方案，不作为当前代码现状。

它描述后台“智能发布视频”板块的目标流程：上传视频、存入 OSS、生成发布任务、下发给手机 App、回传发布结果。

## 2. 当前状态

1. 当前代码里未形成该功能闭环。
2. 该方案不进入当前验收承诺。
3. 如后续继续做，需先补实现方案和接口设计。

## 3. 方案边界

1. 视频先入 OSS，再进入任务。
2. 业务元数据留数据库，OSS 只存文件。
3. AccessKey 只放服务端环境变量。
4. 上传、审核、发布、回传都应可追踪。
