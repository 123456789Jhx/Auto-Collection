本文只记录代码审查的简要结论，按日期倒序维护；同一天的记录合并到一个日期块内，并按风险等级分层。详细问题、卡点、修复过程和验证结果维护到 `卡点与问题记录.md`、`项目记录.md` 或对应提交说明中。

## 2026-09-10 业务脚本更新与加载修复

- P1 已修：合法 SHA 但入口缺失/抛错会反复选中坏覆盖包。现在记录失败版本和指纹，下一引擎整套选择 APK，拒绝重复下载该版本；真实 main 四场景测试证明缺入口、导入异常、初始化异常隔离，普通任务异常不隔离。
- P2 已修：引擎停止失败仅本地日志、远端只见 APPLIED。现在补 FAILED(phase=restart)，保留真实运行版本和 pending 版本；不循环重启正在运行的引擎。
- 审查通过：APK 基线/业务与基座指纹、单调版本、激活完整性、原子目录回滚、固定运行副本、原生 core 单实例、禁止业务混层及曲线失败不直线降级。构建链另行独立审查，7 项 helper 与 11 项 API mock 通过。
- 待验收：未真实打包/部署。必须验证 AutoJS 原生 require/Java SHA 与 Android cubicTo、watchdog 下一引擎恢复、实际运行版本及动作日志；Node 模拟不等于真机通过。异常强杀可能留下私有运行副本，本轮不清扫其他引擎目录，以免误删仍被使用的脚本。
- 发布约束：旧 APK 不识别新兼容门禁，必须先升级目标设备再发布新业务包；跨对话须确认同一源码快照和唯一执行者。旧构建测试有共享暂存副作用且契约过时，已明确排除，不能直接跑全仓测试替代联合打包验收。

## 2026-09-08 评论历史到底提示与连续手势

- 已检查：普通 tap/swipe 不变；新增保持使用同一触点的 continueStroke，有限保持时长在 OCR 前提交给系统，避免慢 OCR 无限按住。只有有效保持窗口内的截图可参与提示判断；取消或失败不能当成成功到底，采集失败阻止正常切房。
- 验证：79 项定向测试通过，包含先移动再截图、2 秒自动松手、立即/延迟异常、取消、STOP、拒绝续接后的短释放动作及连续两房；十个 JS 语法检查通过，扩展 21 项失败均为既有。
- 待真机：Node 测试通过 Android 接口替身验证时序，不能证明实际 JavaAdapter/主线程回调可靠；API 26 以下不支持连续手势，必须明确失败。系统拒绝保持/释放或回调异常时，需核对现场日志与触点释放，不能标记设备验收通过。本轮未部署。

## 2026-09-13 小米14最近任务误划审查

- P1：匿名居中卡片、模糊抖音正文及跨卡父容器可能误删燎原星火。小米14入口改为独立的严格任务身份与几何校验，不再访问这些兜底；非小米策略未扩改。
