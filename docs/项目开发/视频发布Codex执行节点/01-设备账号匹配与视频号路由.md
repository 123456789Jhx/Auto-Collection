# 01-设备账号匹配与视频号路由

## 目标

统一设备匹配规则：外部接口任务明确平台，但无论抖音还是视频号，都应先按外部任务里的抖音账号标识路由到同一台设备。

视频号发布不是用 `wechatChannelsName` 作为主路由键，而是：

1. 使用外部任务的 `accountName` 匹配设备绑定的抖音账号名称或抖音号 ID。
2. 命中设备后，如果平台是视频号，再检查该设备是否有视频号发布能力，即 `wechatChannelsName` 已绑定。
3. 没有视频号绑定时，不下发，记录并回写“未发布：该设备未绑定视频号”。

## 当前问题

前序只读核对发现：

- `account-data-platform/apps/api/src/services/publish-match.service.ts` 中，视频号任务当前按 `wechatChannelsName` 匹配。
- 测试 `publish-match.service.test.ts` 中已有用例固化了“视频号只按 channel account binding 匹配”的旧行为。
- 这会导致同一抖音账号的抖音任务和视频号任务被路由到不同设备，违背“双平台同账号同设备”的执行预期。

## 不要改什么

- 不要删除设备绑定里的 `wechatChannelsName` 字段；它仍用于判断设备是否具备视频号发布能力。
- 不要让视频号任务按视频号名称独立路由。
- 不要给外部接口任务缺少抖音账号时兜底匹配未绑定设备。
- 不要影响手动测试/粘贴发布中用户明确选择设备的场景；这些场景不需要重新做账号匹配。

## 实施步骤

1. 调整匹配函数语义。
   - 在 `publish-match.service.ts` 中，把外部接口任务的设备匹配统一改为抖音账号匹配。
   - 匹配字段：
     - `accountProfile.douyinAccountName`
     - `accountProfile.douyinAccountId`
   - 平台为视频号时，也走同一套抖音账号匹配。

2. 保留视频号能力检查。
   - 匹配出设备后，如果任务平台为视频号：
     - 检查设备 `accountProfile.wechatChannelsName` 是否存在。
     - 不存在则不创建命令，记录未发布原因。
   - 推荐原因文本：`该设备未绑定视频号`。
   - 如果系统增加结构化失败码，推荐：`CHANNELS_BINDING_MISSING`。

3. 移除外部接口任务的“无账号兜底未绑定设备”。
   - 对 `external_pull` 任务，如果 `accountName` 为空：
     - 不匹配未绑定设备。
     - 标记未匹配或未发布。
     - 推荐原因：`外部任务缺少抖音账号`。
   - 如果其他业务仍要保留未绑定设备兜底，需要限定在非接口定时模式，不要影响外部接口发布。

4. 更新命令 payload。
   - `createPublishVideoTaskCommand()` 中继续保留平台字段。
   - 视频号 payload 应带 `platform: "WECHAT_CHANNELS"` 或现有规范值。
   - 不要把 `wechatChannelsName` 当成匹配依据写入 payload。

5. 更新旧测试。
   - 删除或改写“视频号只按 `wechatChannelsName` 匹配”的旧断言。
   - 新增视频号按抖音账号命中设备的断言。

## 测试要求

在 `account-data-platform/apps/api/src/services/publish-match.service.test.ts` 中至少覆盖：

1. 抖音任务按 `douyinAccountName` 命中设备。
2. 抖音任务按 `douyinAccountId` 命中设备。
3. 视频号任务同样按 `douyinAccountName` 命中设备。
4. 视频号任务同样按 `douyinAccountId` 命中设备。
5. 抖音和视频号同一个外部 `accountName` 命中同一个 `matchedDeviceId`。
6. 只有 `wechatChannelsName` 相同、抖音账号不匹配时，视频号任务不应命中该设备。
7. 视频号命中设备但设备没有 `wechatChannelsName` 时，不创建命令，并记录“该设备未绑定视频号”。
8. 外部任务 `accountName` 为空时，不再匹配未绑定设备。

## 验收口径

- 外部接口视频号任务不再按视频号名称独立路由。
- 同一抖音账号的抖音任务和视频号任务命中同一设备。
- 视频号绑定字段只作为能力检查，不作为主匹配键。
- 无抖音账号的外部任务不会被派给未绑定设备。
- 相关测试全部通过。

## 风险提醒

- 前端设备绑定目前以抖音账号名为必填，这是符合本节点方向的；不要为了视频号路由改成视频号-only 主匹配。
- 如果数据库里已有只填 `wechatChannelsName`、没填抖音账号的设备，改完后它们不会再接视频号外部任务，需要业务侧补齐抖音账号绑定。
- 如果有历史测试依赖“null accountName → 未绑定设备”，需要判断该逻辑是否只属于旧流程或手动场景，不能继续用于接口定时发布。
