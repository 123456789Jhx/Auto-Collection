# 验收口径

## 验收目标

当前验收只看代码里真实存在或正在联调的能力，不把历史方案、废弃方案和未落地设想写成现状。

## 功能验收

| 模块 | 验收口径 |
|---|---|
| 线上后台 | 能打开 `http://106.54.41.106:18080` |
| 设备列表/工作台 | 能展示设备、在线状态、最近心跳、当前任务和常用控制 |
| 任务调度 | 能展示手机实际任务、后台期望任务、最近命令和快捷分配入口 |
| 采集记录 | 能按手机、日期、明细查看手机上报记录 |
| 日志中心 | 能按手机、日期查看运行动态、异常汇总和完整日志 |
| 任务配置 | 能保存公共任务模板和设备级覆盖配置 |
| 设备认证 | 未注册设备访问普通移动端接口返回 401 |
| 设备注册 | 新设备能按 token 注册并绑定唯一设备身份 |
| 视频采集 | 能运行、上报心跳、日志和采集记录 |
| 直播采集 | 能进入公开直播间、停留采样并上报记录 |
| 直播评论 | 能保存画像、指定直播间配置、命令和动作记录 |
| 直播评论发送 | 只有目标直播间确认，且全局急停、任务双开关、审批哈希、审批有效期和运行状态全部通过时才允许真实发送；`allowRealSend` 只能作为派生展示值 |
| 版本管理 | 能查询 Agent 版本和更新事件 |
| 数据清理 | 运行数据表清理后可复查为空 |

## 任务切换验收

1. 后台从视频切到直播评论后，手机不需要重启脚本。
2. 当前在视频页、搜索页、直播间、个人页或异常页时，手机能恢复到目标直播间或给出明确失败原因。
3. STOP 后只停止当前任务，Agent 保持常驻并继续轮询命令。
4. 直播评论切回视频或直播时，旧任务不会继续滑动、搜索或发送。
5. 任务切换日志能和后台命令、心跳、执行记录对上。

## 商品卡组合任务第二版验收

当前第二版只按阶段验收，不把配置准备写成已可执行能力。

| 阶段 | 验收口径 |
|---|---|
| 配置准备 | 后台可保存、校验并预览 `configVersion=2` 配置；V2 开关关闭时启动接口拒绝执行 |
| 无评论灰度 | START、PAUSE、RESUME、STOP 使用同一 assignment；运行冻结 selectedTarget、revision、hash 和 configSnapshot |
| 检查点恢复 | checkpoint v2 能校验 assignment、阶段、配置哈希、设备能力和未确认副作用；不可恢复时上报明确原因 |
| 真实评论 | 评论动作有 assignment 归属、服务端幂等预占、唯一幂等键、动作状态、审批哈希和全局急停 |
| 回退 | 关闭 V2 后拒绝新 START/RESUME，停止在途 V2 assignment，不把 V2 checkpoint 交给第一版 runner |

## 技术验收

1. `bun --filter @app/api typecheck` 通过。
2. `bun --filter @app/api build` 通过。
3. 前端构建通过。
4. 生产 Docker Compose 中 API、Web、PostgreSQL、Redis 正常运行。
5. `http://106.54.41.106:18080/ready` 返回 ready。
6. APK 能打包并安装到测试手机。

## 文档验收

1. 根 `README.md` 能说明项目目标、当前能力、运行方式和文档入口。
2. `docs/方案设计/` 下只保留 `功能方案/` 和 `架构方案/`。
3. 架构方案只保留 `docs/方案设计/架构方案/系统架构方案.md`。
4. 功能方案按实际功能命名，不再保留废弃后续方案。
5. `docs/项目开发/部署说明.md` 单独保留。
6. `docs/项目开发/卡点与问题记录.md` 合并所有卡点文档。
7. `docs/项目开发/error` 不删除、不合并、不作为正式提交文档。

## 不通过条件

1. 旧设备身份继续自动生成脏数据。
2. 未注册设备仍可上报普通接口。
3. 运行数据清理后仍有历史残留。
4. docs 里仍把未落地或已废弃方案写成当前现状。
5. 直播评论真实发送没有明确开关、限制和审计记录。
6. 后台显示暂停或停止，但手机仍继续直播评论动作。
7. 搜索网络异常、空白页或未知弹窗导致脚本无限滑动且无日志。
8. 采集记录或日志中心丢失“手机 -> 日期 -> 明细”的路径。
9. 第二版商品卡配置完成后直接执行，但没有 assignment 快照、状态事件、checkpoint v2、能力门禁或在途回退。
10. `allowRealSend` 被当成独立许可开关，而不是全局急停、任务双开关、审批哈希、有效期和运行状态的派生结果。
