## 3. 文档维护规则

1. 当前范围只能放在 `docs/当前需求/`。
2. 当前有效设计方案统一放在 `docs/方案设计/`，不再散放到项目记录。
3. 已经被当前方案吸收的旧稿不再复制到当前需求目录。
4. 会议原文、截图、XML、旧稿只作为证据或来源，不作为当前实现入口。
5. 新增功能记录优先并入已有专题记录；只有无法合并时才新建专题文档。
