# 评论词抓取真机验收清单

## 1. 准备

- [ ] 确认后端 API 和管理端已启动，测试手机通过 ADB 连接。
- [ ] 在仓库根目录执行 `powershell -ExecutionPolicy Bypass -File .\scripts\package-autojs-apk.ps1`，生成 APK 并覆盖安装到测试机。
- [ ] 前端下发 `isolated_live_comment_entry` 任务，配置 `targetKeyword`（关键词）、`minViewerCount`（人数阈值）和 `batchId`（批次号）。

## 2. 端到端链路

按顺序核对以下 8 个环节：

1. 打开抖音。
2. 搜索 `targetKeyword`。
3. 切换到直播 Tab。
4. 点击并进入第一个直播间。
5. 等待约 3 秒，OCR 识别 viewerCount 区域；人数低于 `minViewerCount` 或识别不到时自动下滑切换直播间并重测，最多尝试 10 个房间；达到阈值后停留。
6. 打开评论区并上滑 6 次（运行时将配置 clamp 到 0–20），每页 OCR；按冒号 `:`/`：` 分隔用户名和正文，过滤噪声、跨页去重，正文超过 100 字丢弃。
7. 回执上报：`resultJson.comments` 为数组，每项包含 `commentText` 和 `sources[]`；来源字段为 `deviceId`、`roomKey`、`pageIndex`、`userName`。
8. 前端候选列表显示“待入库”；勾选候选并确认后写入词库，未勾选项仍保持 `PENDING`。

## 3. 观察点与失败原因

| 环节 | 观察点 | 可能失败原因 |
| --- | --- | --- |
| 打开/搜索/直播 Tab | 抖音打开且关键词结果出现 | APK 未安装、权限不足、网络或搜索接口异常 |
| 进入直播间 | 页面进入直播间且未回退 | 点击坐标漂移、页面加载超时 |
| 人数 OCR | 识别 `8500`、`1.2万`、`1万+` 并正确比较 | viewerCount 区域变化、OCR 无文本；连续 10 个房间不达标返回 `NO_ROOM_MATCHED` |
| 评论分页 | 实际上滑 6 次，页面 OCR 有结果 | 评论区未展开、滑动失败、OCR 失败或连续页面无新增评论 |
| 停止任务 | 停止令立即中断滑动并回传已抓取 partial | 网络延迟、停止回执超时 |
| 回执 | comments 数组及 sources 字段完整 | API 不可达、批次号或设备号缺失 |
| 待入库展示 | 候选出现且标记待入库 | 管理端查询失败、批次筛选不一致 |
| 确认入库 | 仅勾选项进入词库，重复确认不产生重复词 | 词库写入失败、幂等键或权限问题 |

## 4. 通过标准

- [ ] 上述 8 个环节全部符合预期。
- [ ] 数据库中出现已勾选评论词，未勾选候选仍为 `PENDING`。
- [ ] 未达到人数阈值时最多切换 10 个房间；达到阈值后不再切房。
- [ ] 评论分页实际滑动次数与配置一致，默认 6 次且不超过 20 次 clamp。
