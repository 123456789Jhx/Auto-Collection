# 后台 UI 视觉优化卡点与解决记录

记录日期：2026-06-28

线上地址：http://106.54.41.106:18080

## 1. 背景

本次调整接在 `后台UI页面收敛卡点与解决记录_2026-06-28.md` 之后。上一轮已经完成工作台和设备运行合并、任务调度中文化、直播评论参数页收敛，但页面视觉仍然存在“卡片散、按钮挤、状态不够醒目”的问题。

本轮只做后台 Web 视觉和必要 class 调整，不改变 API、数据库、设备命令语义和原有点击流程。

## 2. 保留逻辑

1. 工作台设备卡片点击仍然打开右侧设备详情抽屉。
2. 卡片内启动、暂停、恢复、刷新配置、停止仍然走原有 `createMobileCommand`。
3. 任务调度页仍然通过 `createTaskAssignment` 切换视频、直播、直播评论和停止。
4. 直播评论页仍然用于修改设备直播评论参数，并保留设备行点击打开详情抽屉。
5. 采集记录和日志中心的“手机卡片 -> 日期卡片 -> 明细”路径本轮未修改。

## 3. 本轮调整

| 页面 | 调整 |
|---|---|
| 工作台 | 设备卡片改为更紧凑的横向监控行，左侧设备身份，中间心跳状态，右侧进度、数据和操作按钮分区展示 |
| 工作台 | 心跳状态增加显式 `heartbeat-ok / heartbeat-warn / heartbeat-danger` class，避免依赖 CSS `:has()` |
| 工作台 | 设备操作按钮改为图标加短文案，刷新配置缩短为“配置”，降低横向拥挤 |
| 任务调度 | 指标卡、筛选区、表格和详情卡统一边框、阴影、间距和顶部状态色 |
| 任务调度 | 行内操作改为图标化的“视频 / 直播 / 评论 / 停止”按钮组 |
| 直播评论 | 行内启动、暂停、配置按钮改为和工作台一致的图标按钮样式 |
| 通用样式 | `ops-*` 和 `scheduler-*` 页面统一背景、卡片阴影、表格选中态、按钮高度和圆角 |

## 4. 卡点与解决

| 卡点 | 原因 | 解决方式 |
|---|---|---|
| 工作台设备行看起来像临时拼出的卡片 | 身份、心跳、进度、统计、按钮的视觉权重没有区分 | 改成五列监控行，心跳状态独立色块，操作区独立按钮组 |
| 心跳状态不够醒目 | 字号和色块面积偏小，离线状态没有形成第一视觉焦点 | 心跳数字加大加粗，危险状态使用浅红底和红色侧边线 |
| 操作按钮横向拥挤 | “刷新配置”文案过长，按钮之间没有工具组关系 | 改为图标按钮和短文案，操作区使用 5 等分按钮组 |
| CSS 状态依赖 `:has()` | 状态色由子元素反推父卡片，兼容和可维护性不够直接 | React 渲染时直接给父卡片加 `heartbeat-${tone}` |
| 调度页按钮像普通表单按钮 | 视频、直播、评论、停止没有形成明确动作组 | 统一为图标化小按钮，主动作使用蓝色，停止使用红色警示 |
| 三个页面风格不一致 | 工作台、调度、直播评论分别使用不同按钮和卡片密度 | 抽出同一套卡片阴影、边框、圆角、表格和 mini button 视觉规则 |
