# 抖音账号名同步风险修复记录

- 日期：2026-06-30
- 范围：手机端心跳、后台 API、后台设备展示
- 关联方案：`docs/方案设计/功能方案/抖音账号名同步风险修复方案.md`

## 卡点

抖音账号名同步最初放在手机端空闲循环里执行，会进入抖音个人页读取文本。这个行为和一键启动、任务切换共用同一个抖音 UI，存在抢页面、打断任务启动、误覆盖设备名的风险。

## 处理

1. 手机端默认关闭账号名自动同步，并移除主循环自动同步入口。
2. 后端心跳继续接收 `douyinAccountName`，但不再用它覆盖 `deviceName`。
3. 后台页面统一优先展示最近心跳里的抖音账号名；没有账号名时回退到设备名称和设备码。
4. 设备管理名继续保留为后台人工维护字段。

## 验证

1. `node --check` 通过：`collector-app.js`、`heartbeat.js`、`douyin.js`、`uploader.js`、`config.js`。
2. `bun --filter @app/api typecheck` 通过。
3. `bun --filter @app/web typecheck` 通过。
4. 风险扫描未命中空闲自动同步、`allowOpenApp: true` 或心跳覆盖设备名。
