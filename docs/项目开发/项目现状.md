# 项目现状

更新时间：2026-06-23

## 1. 当前阶段

项目当前处于测试联调阶段，主线拆成两层：

1. 常驻层：设备注册、心跳、日志、命令轮询和版本检查。
2. 任务层：刷视频、刷直播、直播评论三个独立任务。

## 2. 当前已具备能力

| 模块 | 当前状态 |
|---|---|
| 后台监控 | 已部署到 `http://106.54.41.106:18080` |
| 设备注册认证 | 已支持唯一设备 ID 和设备 token 绑定 |
| 心跳常驻 | 已支持常驻、心跳、日志、命令轮询 |
| 刷视频 | 已有推荐流识别、候选记录和运行状态上报基础 |
| 刷直播 | 已有直播流识别、停留和上下文恢复基础 |
| 直播评论 | 已支持画像、配置、命令和动作记录，指定直播间链路继续收敛 |
| 版本管理 | 已支持 Agent 版本检查和更新事件 |

1. 不接入抖音官方 API。
2. 不绕过验证码、登录校验或平台风控。
3. 不采集非公开内容。
4. 不默认开启点赞、关注、私信等真实互动。
5. 不把未落地方案写成当前现状。
