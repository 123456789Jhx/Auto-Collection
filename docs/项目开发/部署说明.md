# 部署说明

## 线上环境

- 服务地址：`http://106.54.41.106:18080`
- API 地址：`http://106.54.41.106:18080/api/v1`
- 健康检查：`http://106.54.41.106:18080/ready`

## 本地开发

```powershell
cd account-data-platform
bun install
bun run db:push
bun run dev
```

默认地址：

- API: `http://localhost:3010`
- Web: `http://localhost:3020`
- PostgreSQL: `postgres://postgres:123456@localhost:5432/auto_collection`

## 生产部署

生产环境使用 Docker Compose。

```bash
cd /opt/auto-collection/account-data-platform
docker compose --env-file .env.production -f docker-compose.production.yml build api web
docker compose --env-file .env.production -f docker-compose.production.yml up -d
curl http://127.0.0.1:18080/ready
```

## 清理运行数据

只清理运行期数据，不默认删设备和任务配置。

```bash
cd /opt/auto-collection/account-data-platform
docker exec auto-collection-postgres sh -lc 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -v ON_ERROR_STOP=1 -c "truncate table live_comment_actions, agent_update_events, agent_versions, mobile_commands, device_task_configs, device_log_files, runtime_logs, device_heartbeats, collection_records, collector_devices cascade;"'
```
