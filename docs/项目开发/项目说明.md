## 2. 当前目标

当前项目只围绕已落地代码做三件事：

1. 手机 Agent 常驻运行、拉配置、上报心跳和日志。
2. 后台集中查看设备、任务、采集记录、日志和命令回执。
3. 直播评论在后台配置、手机执行和审计记录之间形成闭环。

## 3. 当前主链路

1. 手机端注册设备 token。
2. 手机端轮询当前任务和命令。
3. 手机端上报采集记录、心跳、运行日志、日志文件和直播评论动作。
4. 后台展示设备、任务、记录、日志、直播评论和版本信息。
5. 后台下发命令后，手机 Agent 主动拉取并执行。

## 4. 当前已实现能力

1. 设备注册、认证、心跳、命令轮询。
2. 采集记录、运行日志、日志文件上报与查询。
3. 设备任务配置与任务进度查看。
4. 直播评论动作记录、设备画像、指定直播间配置和远程控制。
5. Agent 版本检查和更新事件记录。

## 5. 当前不做

1. 不接入抖音官方 API。
2. 不绕过验证码、登录校验或平台风控。
3. 不采集非公开内容。
4. 不默认开启点赞、关注、私信等真实互动。
5. 不承诺平台推荐、标签或账号权重结果。

## 6. 技术结构

| 模块 | 技术 |
|---|---|
| 手机端 | AutoX.js / JavaScript |
| 后台 API | Bun + Hono |
| 后台 Web | React 19 + Vite + Ant Design |
| 数据库 | PostgreSQL + Drizzle ORM |
| 缓存 | Redis |
| 部署 | Docker Compose |

## 8. 成功指标

1. 线上后台可查看设备、任务、记录和日志。
2. 新版 APK 或 Agent 可唯一注册，不再共用旧设备身份。
3. 未注册设备访问普通接口返回 401。
4. 直播评论配置可保存、下发、回传和审计。
5. 运行数据清理后可复查为空。
