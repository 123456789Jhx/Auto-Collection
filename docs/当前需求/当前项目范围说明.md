# 当前项目范围说明

## 1. 文档目标

本文只描述当前版本真实有效的范围，不承接历史产品说明或未落地方案。

## 2. 当前范围

当前项目是“手机 Agent + 后台监控 + 远程命令 + 直播评论审计”的闭环。

已实现链路包括：

1. 设备注册与认证。
2. 任务配置下发与拉取。
3. 采集记录、心跳、日志、日志文件上报。
4. 直播评论动作记录、设备画像和指定直播间配置。
5. Agent 版本检查与更新事件记录。

## 3. 当前平台范围

后台当前只做监控、配置、排障和审计，不做完整内容生产平台。

| 能力 | 范围 |
|---|---|
| 设备管理 | 注册、认证、在线状态、最近心跳、设备任务配置 |
| 任务配置 | 搜索关键词、匹配关键词、时长、自动启动、评论相关配置 |
| 采集记录 | 候选内容、关键词命中、屏幕文本、评论片段 |
| 运行日志 | 启动、暂停、停止、失败、异常页面 |
| 远程命令 | 启动、暂停、恢复、停止、刷新配置、版本检查 |
| 直播评论 | 动作计划、跳过、失败、发送记录和审计 |
| 版本事件 | Agent 版本检查、下载、应用和上报 |

## 4. 直播评论边界

直播评论默认不做真实发送扩展。

| 项 | 当前口径 |
|---|---|
| 真实发送 | 默认关闭 |
| 指定直播间 | 支持 |
| 设备画像 | 支持 |
| 计划记录 | 支持 |
| 跳过/失败/发送审计 | 支持 |
| 点赞、关注、私信 | 默认不做 |

## 5. 当前技术栈

| 模块 | 技术 |
|---|---|
| 手机运行环境 | AutoX.js / Auto.js |
| 手机脚本语言 | JavaScript |
| 后台服务 | Bun runtime + Hono |
| 后台数据库 | PostgreSQL |
| 后台 ORM | Drizzle ORM |
| 后台缓存 | Redis |
| 后台前端 | React 19 + Vite + Ant Design |
| 部署 | Docker Compose |

## 6. 当前不做

1. 不接入抖音官方 API。
2. 不做完整内容生产工作流。
3. 不默认启用自动点赞、评论、关注、私信。
4. 不绕过验证码、登录校验或平台风控。
5. 不批量下载完整视频。
6. 不采集非公开内容。
