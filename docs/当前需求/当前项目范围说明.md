# 当前项目范围说明

## 1. 文档目标

本文是当前阶段的唯一范围口径。具体设计方案统一放在 `docs/方案设计/`；历史产品说明、会议稿、试运行方案和过程记录只作为项目记录，不能覆盖本文定义的当前范围。

## 2. 当前范围

本项目当前实现“手机自动化采集 + 后台监控 + 远程命令 + 智能发布视频”的小范围闭环。

采集链路是：手机脚本浏览公开可见的农业相关视频和直播，读取屏幕可见文本、运行状态和候选内容；后台接收采集结果、心跳、日志和命令回执，用于观察设备是否正常运行、农业内容命中是否稳定、异常原因是否可复查。

发布链路是：同事在后台上传待发布视频，后台将视频存入阿里云 OSS，生成发布任务并分配给手机 App；手机 App 主动拉取任务，下载视频并按任务配置进入平台发布页完成发布，再把发布结果、异常原因和截图证据回传后台。

第一阶段必须覆盖：

1. 使用 AutoX.js / Auto.js 在 Android 手机上运行脚本。
2. 打开抖音并进入推荐流、搜索流或直播观察场景。
3. 通过截图、OCR、无障碍控件读取当前页面可见信息。
4. 使用农业关键词判断是否为候选内容。
5. 命中后采集 OCR 文本、截图、可见互动指标、可见热门评论和运行上下文。
6. 将候选记录写入手机本地 JSON 缓存。
7. 将候选记录、运行日志、心跳状态上传到后台。
8. 后台展示设备状态、任务进度、农业命中率、停止原因和错误日志。
9. 后台记录控制命令，由手机 Agent 主动拉取执行并回写结果。
10. 后台支持同事上传待发布视频到 OSS，并生成发布任务。
11. 手机 App 支持拉取发布任务、下载视频、执行发布并回传结果。

## 3. 当前平台范围

账号数据管理平台当前只做监控、排障、配置和数据接收，不做完整内容生产平台。

当前后台能力：

| 能力 | 范围 |
|---|---|
| 设备管理 | 注册、认证、在线状态、最近心跳、设备任务配置 |
| 任务配置 | 农业搜索关键词、匹配关键词、任务时长、基础策略 |
| 采集记录 | 候选视频、候选直播、屏幕文本、关键词命中、可见评论 |
| 运行日志 | 启动、暂停、停止、上传失败、风险停止、异常页面 |
| 远程命令 | 启动、暂停、恢复、停止、刷新配置、版本检查等命令记录和回执 |
| 智能发布视频 | 视频上传、OSS 存储、发布任务、设备分配、App 发布回传和失败重试 |
| 证据复查 | 通过日志、记录、截图或 XML 判断脚本为何停止、卡住或进入异常页 |

## 4. 直播间互动边界

直播间互动相关内容按阶段处理，不能把只读识别和真实互动混在一起。

| 阶段 | 当前口径 |
|---|---|
| P0 | 允许只读识别直播间状态、采样公开可见评论、记录采样结果 |
| P1 | 允许对已采样评论做纯逻辑分类、去重、触发识别和计划记录 |
| P2 | 仅作为风控、冷却、审计、审批和开关方案；真实执行需单独确认 |
| P3 | 点赞、关注等扩展默认关闭，必须独立任务、独立审批、独立验收 |

当前默认不启用真实评论发送、点赞、关注、私信等动作。指定直播间测试场景可以在明确授权后打开 `targetRoom.allowRealSend`，但必须受发送条数、发送间隔、审计日志、验收记录和停用机制约束。

## 5. 当前技术栈

| 模块 | 技术 |
|---|---|
| 手机运行环境 | AutoX.js / Auto.js |
| 手机脚本语言 | JavaScript |
| 手机能力 | 无障碍服务、悬浮窗、截图权限、可用 OCR 能力或插件 |
| 手机配置 | 本地 `config.js` 和后台下发配置 |
| 手机存储 | 本地 JSON 缓存、日志文件、截图文件 |
| 后台服务 | Bun runtime + Hono |
| 后台数据库 | PostgreSQL |
| 后台 ORM | Drizzle ORM |
| 后台缓存 | Redis |
| 对象存储 | 阿里云 OSS |
| 后台前端 | React 19 + Vite + Ant Design |
| 部署 | Docker Compose |

## 6. 当前不做

1. 不接入抖音官方 API。
2. 不做 AI 分析、知识库和完整素材库。
3. 不做完整内容生产工作流；智能发布只覆盖上传、存储、任务分发、App 发布和结果回传。
4. 不默认启用自动点赞、评论、关注、私信。
5. 不做给主营账号刷互动、刷有效账户等行为。
6. 不绕过验证码、登录校验或平台风控。
7. 不批量下载完整视频。
8. 不采集非公开内容。
9. 不承诺或伪造平台对账号的标签识别结果，只记录脚本实际浏览和命中的内容证据。
10. 不把 OSS AccessKey 下发到前端或手机端。
