# PRD功能说明书

## 项目目前实现的功能

1. 设备注册与认证：设备可以唯一注册，系统可以识别每台设备的身份。
2. 设备常驻运行：设备可以持续在线，持续上报状态、心跳和运行信息。
3. 任务配置下发与拉取：后台可以配置任务，设备可以拉取当前任务并执行。
4. 采集记录上报与查看：设备可以上报采集结果，后台可以查看和筛选记录。
5. 运行日志查看：设备运行过程中的日志可以上报，后台可以查看。
6. 远程命令控制：后台可以对设备下发启动、暂停、恢复、停止、刷新配置、版本检查等命令。
7. 直播评论配置与记录：后台可以配置直播评论相关内容，设备可以执行并回传计划、跳过、失败和发送记录。
8. 指定直播间支持：可以围绕指定直播间进行评论相关执行。
9. 版本检查与更新记录：设备可以检查版本，后台可以查看更新事件。
10. 后台统一查看：后台可以查看设备、任务、记录、日志、命令和版本信息。

## 需要实现的功能

1. 设备状态展示完善：更完整地展示设备在线状态、异常状态和最近运行情况。
2. 任务配置展示完善：把设备任务配置整理成产品更容易理解和维护的功能项。
3. 采集记录筛选完善：支持按设备、任务、时间、关键词等方式快速查看记录。
4. 日志查看完善：支持更快定位设备问题、执行异常和失败原因。
5. 远程控制闭环完善：补齐命令下发、执行结果和失败原因的完整闭环。
6. 直播评论功能完善：继续完善评论配置、指定直播间、发送结果、跳过原因和失败原因。
7. 版本更新展示完善：继续完善版本发布、检查、应用和更新结果展示。
8. 后台入口统一：把设备、任务、记录、日志、评论、版本放在统一管理入口下。
