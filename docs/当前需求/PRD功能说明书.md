# PRD功能说明书

## 1. 文档定位

本文是 Auto Collection 当前阶段的主 PRD。产品和开发后续都以这份文档作为共同维护入口。

本文只描述当前有效需求，不承接历史旧稿和未落地方案。凡是会影响实现、验收、页面、接口、数据库或手机端行为的变更，都应先更新本文，再同步方案设计和验收口径。

## 2. 维护规则

1. 产品负责业务目标、范围、优先级和验收口径。
2. 开发负责实现约束、接口、数据结构、状态流转和风险说明。
3. 所有新增、删除、调整都要写清楚变更原因。
4. 影响实现的内容必须同步到 `docs/方案设计/`。
5. 影响验收的内容必须同步到 `docs/项目开发/验收口径.md`。
6. 本文保留版本记录，避免口头同步丢失结论。

## 3. 项目目标

当前项目的目标是形成“手机 Agent + 后台监控 + 远程命令 + 直播评论审计”的闭环。

当前阶段重点不是完整内容生产平台，而是先把以下能力做稳定：

1. 设备可注册、可认证、可识别。
2. 手机可常驻运行、可上报心跳和日志。
3. 后台可查看设备状态、采集记录、运行日志和命令回执。
4. 直播评论可配置、可执行、可审计。
5. Agent 版本可检查、可上报更新事件。

## 4. 业务边界

### 4.1 当前范围

| 能力 | 范围 |
|---|---|
| 设备管理 | 注册、认证、在线状态、最近心跳、设备任务配置 |
| 任务配置 | 搜索关键词、匹配关键词、时长、自动启动、评论相关配置 |
| 采集记录 | 候选内容、关键词命中、屏幕文本、评论片段 |
| 运行日志 | 启动、暂停、停止、失败、异常页面 |
| 远程命令 | 启动、暂停、恢复、停止、刷新配置、版本检查 |
| 直播评论 | 动作计划、跳过、失败、发送记录和审计 |
| 版本事件 | Agent 版本检查、下载、应用和上报 |

### 4.2 当前不做

1. 不接入抖音官方 API。
2. 不做完整内容生产工作流。
3. 不默认启用自动点赞、评论、关注、私信。
4. 不绕过验证码、登录校验或平台风控。
5. 不批量下载完整视频。
6. 不采集非公开内容。

## 5. 用户角色

| 角色 | 目标 | 主要操作 |
|---|---|---|
| 运营/产品 | 看设备是否在线、是否有异常、是否完成任务 | 查看看板、设备、日志、记录、配置 |
| 开发/运维 | 判断系统是否正常、定位异常、处理版本更新 | 查看日志、命令、版本事件、设备状态 |
| 手机 Agent | 拉取任务、执行任务、上报状态 | 注册、心跳、日志、记录、命令回执 |

## 6. 核心流程

1. 手机端注册设备 token。
2. 手机端轮询当前任务和命令。
3. 手机端上报采集记录、心跳、运行日志、日志文件和直播评论动作。
4. 后台展示设备、任务、记录、日志、直播评论和版本信息。
5. 后台下发命令后，手机 Agent 主动拉取并执行。

## 7. 功能说明

### 7.1 设备注册与认证

需求说明：

1. 设备必须唯一注册。
2. 设备主标识使用 `deviceCode`。
3. 手机本地密钥使用 `deviceToken`。
4. 未注册设备访问普通移动端接口返回 401。
5. 后台设备列表不展示 token 明文。

### 7.2 任务配置

需求说明：

1. 后台可以配置搜索关键词、匹配关键词、运行时长和自动启动开关。
2. 手机端拉取当前任务配置后执行。
3. 配置变更后不强制打断当前任务，下一次拉取生效。

### 7.3 采集记录

需求说明：

1. 手机端命中候选内容后上报记录。
2. 记录至少包含平台、场景、关键词、标题、屏幕文本、评论片段和原始 payload。
3. 后台支持按设备、任务、关键词、时间筛选。

### 7.4 运行日志

需求说明：

1. 手机端保留本地日志。
2. 后台支持查看结构化日志和日志文件。
3. 异常日志要能反查上下文。

### 7.5 远程命令

需求说明：

1. 后台可下发启动、暂停、恢复、停止、刷新配置、版本检查命令。
2. 手机端主动拉取命令。
3. 命令必须有回执和状态变更记录。

### 7.6 直播评论

需求说明：

1. 后台可保存账号画像、直播评论配置和指定直播间配置。
2. 手机端可按配置生成评论计划并回传结果。
3. 默认真实发送关闭。
4. 跳过、失败、发送都要可审计。

### 7.7 版本管理

需求说明：

1. 手机端可检查 Agent 版本。
2. 后台可记录版本发布和更新事件。
3. 更新结果必须能追踪到设备和版本。

## 8. 数据与接口概览

| 类别 | 说明 |
|---|---|
| 设备 | 注册、认证、在线状态、心跳 |
| 任务 | 当前任务配置、策略、自动启动 |
| 记录 | 采集记录、直播评论动作 |
| 日志 | 运行日志、日志文件 |
| 命令 | 下发命令、拉取、回执 |
| 版本 | Agent 版本、更新事件 |

## 9. 验收原则

1. 功能是否真实可用。
2. 数据是否可追踪、可回查。
3. 异常是否有日志和状态。
4. 变更是否同步到方案设计和验收口径。
5. 当前范围之外的内容不写成现状。
