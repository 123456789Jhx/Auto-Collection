# 抖音发布成功后后台清理设计

## 目标

点击“发作品”后持续确认发布状态；只有确认成功才固定等待 30 秒并清理抖音最近任务。发布仍在进行或结果不明确时，不得清理后台。

## 状态判定

1. “发布进度”“正在发布”“上传中”只代表发布中，不能作为成功证据。
2. “发布成功”“作品发布成功”“作品已发布”属于明确成功证据。
3. 备用成功证据必须满足：曾观察到发布中，随后发布中标记消失、发布表单消失，并连续多次稳定看到抖音首页导航。
4. 最大等待保持 180 秒；超时返回 `VERIFY_PENDING`，不进入后台清理。

## 成功收尾

1. 成功确认后固定等待 30 秒。
2. 30 秒结束后再次检查发布中标记；若仍存在，跳过最近任务清理。
3. 调用 AutoJS `recents()` 打开系统最近任务。
4. 先识别包含“抖音”的任务卡片，再基于该卡片边界向左滑出；不按固定位置盲滑其他应用。
5. 抖音卡片移除后等待最近任务页面稳定，识别并点击“燎原星火”完整任务卡片，避免点击会打开应用信息的图标区域。
6. 找不到“燎原星火”卡片或卡片点击失败时调用系统 `home()` 返回手机桌面；该兜底仅记录 warning，不改变已经确认的发布结果。
7. 找不到抖音卡片或滑动失败仍沿用原有保护行为，不扩大已验收清理逻辑的范围。

## 边界

- 仅作用于抖音发布，不影响微信视频号。
- 不改变现有任务创建、素材下载、结果上报和 ACK 主流程。
- 不执行真机点击、热更新发布或 Git 写操作。
