# 外层底座设备接入状态设计

## 目标

本阶段只实现外层底座连接与管理后台“设备接入”状态，不实现内层 Agent、屏幕控制或“打开燎原星火”按钮后的任何接口。

只要手机已开机，且网络、设备身份和后台服务正常，原生外层底座就必须独立于 App 页面和内层 Agent 持续向管理后台发送心跳。用户不能通过 App 内控件停止外层底座。

## 源码边界

- 新外层底座从零编写，唯一可信源码位于 `mobile-agent/android-base`。
- 不迁移、不依赖 `D:\DevTools\Sources\AutoJs6` 中的旧外层业务实现。
- `D:\DevTools` 仅作为 APK 构建工具或临时构建目录。
- 后续构建脚本只能从主项目同步新底座代码到构建目录。
- 本阶段不恢复已物理删除的旧远程唤醒接口。

## 设备身份

- 继续使用现有设备 ID、设备注册凭证和后台设备记录。
- 升级安装后仍映射到原设备，不新建重复设备。
- 注册凭证只存在于手机安全存储和后台，不返回前端。

## 手机外层底座

- Android 开机后依靠已授权的自启动能力启动前台服务。
- 前台服务显示低优先级常驻通知“燎原星火底座连接正在运行”。
- 服务与 App 页面、AutoJS 内层 Agent 生命周期相互独立。
- App 的“一键启动”和“停止运行”只能控制内层 Agent。
- 外层底座每 2 秒尝试上传一次心跳。
- 网络失败时服务不退出，持续重试；网络恢复后自动继续上报。
- Android 可能重复发送系统启动或解锁广播，服务入口必须幂等，始终只保留一个实例。

## 后台判定

后台以实际收到心跳的服务器时间为唯一判定依据，不使用手机上报时间。

每台设备独立保存 `offlineThresholdSeconds`：

- 范围：15 至 150 秒。
- 默认值：15 秒。
- 精度：1 秒。
- 常用刻度：15、30、60、90、120、150 秒。

状态计算：

- 最后一次心跳距现在不超过 6 秒：`ONLINE`。
- 超过 6 秒但未达到该设备离线上限：`RECONNECTING`。
- 达到或超过该设备离线上限：`OFFLINE`。
- 任意状态收到新心跳后立即恢复 `ONLINE`。

后台返回状态时同时返回最后接收时间、已等待秒数、离线上限和重连进度，前端不自行推导另一套业务规则。

## 前端设备接入

“设备接入”列只显示以下状态：

- `在线`
- `正在重新连接 N / 上限秒`
- `离线等待接入`

重连状态使用简单动态进度反馈。状态旁保留一个设置按钮：

- 点击按钮展开 15 至 150 秒滑块。
- 拖动时实时显示秒数。
- 松开后自动保存到当前设备。
- 点击弹层以外区域自动收起。
- 离线设备仍允许修改设置。

本阶段不修改 Agent、屏幕和操作三列，不给空壳按钮接入任何接口。

## 手机端反馈

手机 App 的“底座连接”区域与后台使用同一上限，显示：

- `底座连接正常`
- `正在连接管理后台（已等待 N 秒）`
- `底座连接异常（已超过设备设置的 N 秒）`

异常状态同时显示上次连接成功时间，不提供启停按钮。每次心跳成功响应返回最新离线上限；手机保存最近一次成功取得的设置，首次安装使用 15 秒。

## 数据流

1. 开机后原生前台服务读取既有设备身份和最近一次离线上限。
2. 服务每 2 秒向新的外层心跳接口发送设备身份与必要连接信息。
3. 后台验证设备身份，并用服务器当前时间记录本次接收。
4. 后台在响应中返回该设备最新离线上限。
5. 手机更新本地设置和“底座连接”反馈。
6. 管理后台每秒刷新设备列表，由后台返回统一计算后的设备接入状态和进度。
7. 用户调整滑块后，后台持久化该设备的新上限；手机在下一次成功心跳时同步。

## 异常边界

- 无网络、注册数据无效或后台不可达：手机进入连接中，超过上限后显示连接异常。
- 后台没有收到心跳：先显示重新连接，超过上限后显示离线等待接入。
- 网络延迟导致心跳晚到：一旦后台收到有效心跳，两端立即恢复在线。
- App 未打开、内层 Agent 未启动或被停止：不得影响外层底座心跳。

## 验收标准

- 开机后无需打开 App 或启动内层 Agent，后台能够收到外层心跳。
- 正常连接时，后台显示在线，手机显示底座连接正常。
- 阻断心跳 6 秒后，两端进入正在连接状态并显示递增进度。
- 在设备上限前恢复心跳，两端立即回到正常，不短暂显示离线。
- 达到设备上限后，后台显示离线等待接入，手机显示底座连接异常。
- 每台设备的 15 至 150 秒设置独立、持久化且刷新后不丢失。
- 停止内层 Agent 不影响外层状态。
- 旧远程唤醒接口仍不存在，空壳按钮不会产生网络请求或移动端命令。
