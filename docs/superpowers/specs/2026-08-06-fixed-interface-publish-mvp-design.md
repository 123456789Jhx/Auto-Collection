# 固定接口单设备发布 MVP 设计

状态：待最终确认  
日期：2026-08-06

## 1. 当前目标

第一阶段只验证“外部接口 -> 项目后端 -> 指定设备 -> 成熟发布动作 -> 结果回写”的完整流通性。

当前只接入一台测试设备。单设备闭环稳定后，再逐台增加设备验证多设备调度和并发，不在本阶段实现多接口管理或 Token 数据库持久化。

## 2. 固定接口规则

- 只允许使用当前已经确认的外部接口地址。
- Token 继续由项目后端环境变量 `PUBLISH_EXTERNAL_TOKEN` 提供。
- Token 不进入前端、数据库、日志、错误详情或手机命令。
- 接口地址保存到现有 `remote_script_configs.config_payload`。
- 配置通过现有 `configId` 参与运行、领取、回写和监控链路，不改动现有调度架构。
- 本阶段不创建 `publish_interface_credentials` 表，不执行 `0031_publish_interface_credentials` 迁移。

## 3. 前端范围

“视频发布 > 接口定时”继续作为唯一操作入口，按顺序保留：

1. 固定接口连接
2. 匹配设备
3. 运行控制
4. 运行监控与告警

固定接口连接区域只展示配置名称、接口地址、启用状态和“测试连接”。前端不提供：

- 新建接口配置
- 编辑接口地址
- Token 输入或更换
- 环境变量名输入
- 高级执行参数编辑
- 删除固定接口配置

## 4. 初始化方式

通过现有项目后端管理 API 一次性创建固定配置。配置内容使用：

- `sourceMode`: `external_pull`
- `externalBaseUrl`: 当前固定接口地址
- `externalTokenEnv`: `PUBLISH_EXTERNAL_TOKEN`
- 已验证的发布动作默认参数
- `platforms`: `['抖音']`

数据库持久化后，正常重启前后端不需要重新初始化。部署全新数据库时，再执行一次相同初始化操作。

## 5. 单设备真机流程

使用当前测试设备及其已绑定账号：

- 设备：`device_03be8de3a35ae0ce`
- 抖音名称：`开心幸福一家人`
- 抖音号：`41218954470`

验证顺序：

1. 检查前后端、数据库、设备心跳和业务脚本版本。
2. 初始化固定接口配置。
3. 在“接口定时”执行测试连接。
4. 检查当前设备绑定唯一且完整。
5. 设置当前时间之后的合法发布时间和最大同时发布设备数 `1`。
6. 开启总任务并确认本次绑定。
7. 到点后观察领取、素材转换、设备派发和手机发布。
8. 检查手机结果回传、本地任务状态和外部接口状态回写。
9. 记录失败发生在接口、后端流通、设备执行还是结果回写阶段。

真实领取外部任务和真机发布属于本次已授权测试范围。测试只使用当前单台设备，不主动启动第二台设备。

## 6. 错误处理

- 固定 Token 缺失：阻止测试连接和任务启动，提示后端环境变量未配置。
- 接口认证失败：停止联调并提示检查固定 Token，不在前端请求 Token。
- 接口不可达：提示检查固定 URL、网络或 TLS。
- 未匹配到设备：不领取该账号任务，先修复设备绑定。
- 领取后流通失败：保留现有隔离、告警和人工处理机制。
- 手机发布动作失败：按现有手机结果处理，不修改成熟动作脚本。
- 状态回写失败：进入现有 outbox 重试或人工核对流程。

## 7. 验收标准

- 前端没有接口新增、编辑、删除或 Token 输入控件。
- 固定接口测试连接成功。
- 外部任务只发送给当前绑定设备。
- 素材转换继续复用粘贴发布已经验证的转换逻辑。
- 手机继续复用成熟发布动作脚本。
- 发布结果能够回到项目后端并按现有协议回写外部接口。
- Token 不出现在前端响应、数据库、日志或手机 payload。
- 单设备完整闭环通过后，才进入多设备验证。

## 8. 暂停内容

以下已讨论方案保留为后续演进，但当前 MVP 不执行：

- 多接口配置管理
- Token AES-256-GCM 数据库存储
- Token 更换界面
- `publish_interface_credentials` 表和 0031 迁移
- 多设备并发压力验证

专项设计 `2026-08-06-interface-publish-credentials-design.md` 和实施计划 `2026-08-06-interface-publish-credentials.md` 暂停，不作为本阶段实现依据。

## 9. 保护边界

- 不修改外部接口路径、参数和状态回写协议。
- 不修改成熟手机发布动作。
- 不修改父文档 `通过接口发布视频架构设计.md`。
- 撤销范围只限于今天新增且尚未完成的凭据持久化代码，不回退昨晚已完成的接口发布主流程或用户其他改动。
