# 接口定时单页操作与凭据持久化设计

状态：已确认  
日期：2026-08-06

## 1. 目标

“通过接口发布视频”的用户操作全部收敛到“视频发布 > 接口定时”。用户不需要切换到“发布设置”或“设备账号”完成接口发布任务。

每个接口配置独立保存接口地址和 Token。Token 只在新建或明确更换时输入，关闭页面、退出登录或重启浏览器后不需要重新输入。

## 2. 已确认决策

- “接口定时”是通过接口发布视频的唯一操作入口。
- 每个接口配置分别保存 Token，不使用全局共享 Token。
- Token 由后端加密后持久化，不能保存到浏览器本地存储、普通配置 JSON 或日志。
- 编辑配置时不回显 Token，只显示“Token 已配置”。
- 用户不操作 Token 控件时保留旧 Token；点击“更换 Token”并保存后才覆盖。
- 新建配置只要求用户填写配置名称、接口地址和 Token。
- 动作等待、响应延迟、素材目录等技术参数使用系统默认值，不要求普通用户配置。
- 接口地址和 Token 一般不会频繁变更，不建设复杂的凭据中心、版本历史或多级审批。
- 不修改外部发布接口的路径、请求参数和状态回写协议。
- 不修改成熟的手机发布动作脚本。
- 保留旧环境变量 Token 方式作为已有配置的兼容后备。

## 3. 页面结构

“接口定时”页面按以下顺序组织：

1. 接口连接
2. 匹配设备
3. 运行控制
4. 运行监控与告警

### 3.1 接口连接

接口配置列表展示：

- 配置名称
- 接口地址
- Token 状态：已配置或未配置
- 启用状态
- 测试连接
- 编辑
- 删除

新建配置表单只包含：

- 配置名称
- 接口地址
- Token

编辑配置时：

- 配置名称和接口地址正常回显。
- Token 输入框默认不出现，只显示“Token 已配置”。
- 点击“更换 Token”后出现密码输入框。
- 新输入只用于覆盖保存，不提供查看旧 Token 的能力。
- 修改名称或地址时，未填写新 Token 不影响旧 Token。

### 3.2 匹配设备

继续复用当前“匹配设备”入口和绑定表。用户在本页维护：

- 设备 ID
- 抖音名称
- 抖音号
- 绑定完整性和唯一性状态

未绑定设备不参与接口发布；其他未绑定设备不阻塞已完整绑定设备启动任务。

### 3.3 运行控制与监控

运行控制保留：

- 接口配置
- 上午发布时间
- 下午发布时间
- 最大同时发布设备数
- 开启任务
- 停止任务

运行监控和告警继续展示匹配、领取、派发、手机执行、结果回写和异常处理状态。

## 4. 数据模型

新增独立凭据表 `publish_interface_credentials`，不把 Token 写入 `remote_script_configs.config_payload`。

建议字段：

- `id`: UUID 主键
- `tenant_id`: 租户
- `config_id`: 接口配置 ID，唯一外键
- `token_ciphertext`: Base64 密文
- `token_iv`: Base64 随机向量
- `token_auth_tag`: Base64 认证标签
- `key_version`: 加密密钥版本，第一版固定为 `v1`
- `created_at`、`updated_at`
- `created_by`、`updated_by`

Token 使用 AES-256-GCM 加密。加密附加认证数据包含 `tenant_id` 和 `config_id`，防止把一条密文复制到另一配置后仍能解密。

服务端通过 `PUBLISH_CREDENTIAL_ENCRYPTION_KEY` 读取 32 字节 Base64 主密钥。开发环境只在被 Git 忽略的环境文件中配置一次；不能从 JWT 密钥派生，也不能返回给前端。

删除接口配置时，由专用服务在同一事务中删除对应凭据并软删除配置。

## 5. 后端边界

新增接口发布专用配置 API，封装普通配置和加密凭据，不让前端直接操作敏感字段：

- `GET /api/v1/admin/publish-interface/configs`
- `POST /api/v1/admin/publish-interface/configs`
- `PATCH /api/v1/admin/publish-interface/configs/:configId`
- `DELETE /api/v1/admin/publish-interface/configs/:configId`
- 保留现有测试连接 API

创建请求包含配置名称、接口地址和 Token。更新请求中的新 Token 为可选字段；缺省表示保留原凭据。

所有查询响应只返回 `tokenConfigured: boolean`，不返回密文、向量、认证标签、环境变量值或 Token 掩码片段。

创建配置和凭据必须在同一数据库事务中完成。任一步失败时整体回滚，不能留下无凭据配置或孤立凭据。

## 6. Token 使用流程

1. 新建或更换时，管理员在“接口定时”输入 Token。
2. API 校验配置名称、URL 和非空 Token。
3. 后端生成随机 IV，使用 AES-256-GCM 加密并写入凭据表。
4. API 只返回 `tokenConfigured: true`。
5. 测试连接、领取任务和状态回写前，业务服务按 `config_id` 读取并临时解密 Token。
6. Token 只在当前请求内存中使用，不写入普通配置、日志或错误详情。

已有配置如果没有数据库凭据，可继续通过 `externalTokenEnv` 读取环境变量。新建配置默认使用数据库凭据，不要求用户填写环境变量名。

## 7. 默认执行参数

新建接口配置时由后端补齐以下默认值：

- `sourceMode`: `external_pull`
- `responseDelayMsMin`: `700`
- `responseDelayMsMax`: `1200`
- `actionWaitMsMin`: `900`
- `actionWaitMsMax`: `1500`
- `expectedTopicCount`: `5`
- `requireCover`: `true`
- `topicResolveTimeoutMinutes`: `30`
- `downloadDir`: `/sdcard/`
- `publishTimeSlots`: `[]`
- `platforms`: `["抖音"]`

这些字段不在轻量配置表单中展示。上午、下午发布时间和最大同时发布设备数仍由运行控制表单设置，不写入上述旧兼容字段。

## 8. 错误处理

前端使用明确、可操作的状态：

- `Token 未配置`：阻止测试连接和启动任务，引导编辑配置。
- `认证失败`：提示更换 Token，不清除现有 Token。
- `接口不可达`：提示检查接口地址、网络或 TLS。
- `服务端加密密钥未配置`：阻止新建、换 Token 和解密使用，已有数据不做破坏性处理。
- `凭据无法解密`：阻止领取和回写，记录不含 Token 的错误码和配置 ID。

日志禁止记录：

- Token 明文
- Authorization 请求头
- 加密主密钥
- 数据库密文、IV 和认证标签
- 含敏感查询参数的完整素材 URL

## 9. 兼容边界

- 外部接口契约保持不变。
- 手机命令和成熟发布动作保持不变。
- 粘贴发布继续使用“粘贴发布”和“发布设置”，不读取接口凭据。
- “设备账号”保留为通用设备页面，但不是接口发布用户流程的一部分。
- 旧环境变量配置可继续运行，新配置不再要求用户理解环境变量。

## 10. 测试与验收

实现必须遵循测试先行，至少覆盖：

- AES-256-GCM 加密解密往返。
- 相同 Token 多次加密产生不同密文。
- 错误主密钥、篡改密文和错误附加认证数据无法解密。
- 创建配置和凭据的事务一致性。
- API 列表、详情和错误响应不泄露 Token 或加密材料。
- 编辑未提交新 Token 时保留旧 Token。
- 更换 Token 后新 Token 生效，旧 Token 不再使用。
- 删除配置同步清理凭据。
- 数据库凭据优先，旧环境变量方式正常回退。
- 测试连接、领取和回写使用同一凭据解析链路。
- “接口定时”页完成新建、编辑、测试连接、匹配设备、启动和监控。
- 粘贴发布和手机成熟发布动作回归测试通过。

浏览器验收流程固定为：

`接口定时 -> 新建接口配置 -> 测试连接 -> 匹配设备 -> 设置时间和并发数 -> 开启任务 -> 查看监控`

## 11. 非目标

第一版不实现：

- Token 查看或复制
- Token 历史版本和回滚
- 多人审批和凭据轮换计划
- 外部密钥管理平台接入
- 外部接口协议扩展
- 手机发布动作调整
