# 后台监控设计方案

## 1. 文档目标

本文定义当前阶段的账号数据管理平台方案。平台服务只负责接收手机脚本上报的采集数据、心跳和运行日志，并提供监控页面，帮助判断手机是否正常运行、农业内容命中是否稳定、账号浏览内容是否持续偏向农业领域。

当前账号数据管理平台不是完整素材库平台，不接入官方 API，不做 AI 分析审核，不做自动点赞、评论、关注、私信，也不做给主营账号自动互动的功能。

## 2. 设计原则

1. 账号数据管理平台以监控和排障为主，先保证手机端运行可观察。
2. 手机脚本是执行端，账号数据管理平台是配置、接收、展示和审计端。
3. 所有采集结果保留原始文本和原始 payload，便于回放和排查。
4. 后台只记录农业内容浏览和命中证据，不承诺平台账号标签结果。
5. 账号兴趣观测只基于脚本实际浏览记录、农业命中率、关键词覆盖和运行时长。
6. 遇到验证码、登录异常、风控提示时，手机端停止自动操作，后台只展示异常并等待人工处理。

## 3. 技术栈

| 模块 | 技术 | 说明 |
|---|---|---|
| 运行时与包管理 | Bun + Bun workspaces | 遵循部门统一工程规范 |
| 后端 | Bun runtime + Hono | 提供手机端接口和平台管理接口 |
| 入参校验 | Zod | 手机端接口和后台接口统一校验 |
| ORM | Drizzle ORM | 管理 PostgreSQL schema、migration 和类型安全查询 |
| 数据库 | PostgreSQL | 存储设备、任务、采集记录、日志和心跳 |
| 缓存 | Redis | 存储设备在线状态、最近心跳和简单锁 |
| 后台前端 | React 19 + TypeScript + Vite | 管理后台页面 |
| 路由 | TanStack Router | 文件路由，符合部门规范 |
| 服务端状态 | TanStack Query | 管理列表、详情、看板等接口数据 |
| UI | Ant Design | 表格、表单、筛选、详情页 |
| 接口文档 | OpenAPI 文档或接口 Markdown | 方便联调手机脚本 |
| 部署 | Docker Compose | 第一阶段单机部署 |

技术栈选择说明：

1. 当前阶段虽然只是轻量监控后台，但项目可能由同事接管，必须遵守 `部门统一技术架构规范_V1.0.md`。
2. 前后端、共享类型和工具代码统一使用 TypeScript，接口 DTO、字段命名和类型约束保持一致。
3. 后端采用 Hono 的 route、service、repository 分层，避免把业务逻辑写在路由里。
4. 数据库 schema 和 migration 由 Drizzle 统一管理，禁止手工直接改库结构。
5. 第一阶段不接入 AI/RAG，但目录和数据模型保留后续扩展空间。

## 4. 总体结构

```text
手机 AutoX.js 脚本
  -> 拉取任务配置
  -> 浏览农业搜索流/推荐流/直播流
  -> 本地保存候选记录和日志
  -> 上传候选记录、心跳、运行日志

账号数据管理平台
  -> 接收手机上报
  -> 写入 PostgreSQL
  -> 更新 Redis 在线状态
  -> 展示设备监控、采集数据、运行日志、任务配置
```

## 5. 功能范围

### 5.1 设备监控

设备监控用于判断每台手机是否在线、是否正在运行、是否异常停止。

字段：

| 字段 | 说明 |
|---|---|
| 设备编号 | 手机脚本配置的 `deviceId` |
| 设备名称 | 后台给设备起的名称 |
| 平台 | 当前运行平台，如 `douyin` |
| 状态 | `offline`、`online`、`running`、`paused`、`error` |
| 当前任务 | 正在执行的任务编号 |
| 最后心跳 | 最近一次心跳时间 |
| 已浏览数量 | 当前任务浏览的视频数量 |
| 已采集数量 | 当前任务命中的农业候选数量 |
| 当前阶段 | `video`、`live` |
| 停止原因 | `manual_stop`、`risk_control`、`permission_missing`、`task_finished` 等 |

### 5.2 任务配置

后台维护任务配置，手机端启动时拉取最新配置。

配置项：

| 字段 | 说明 |
|---|---|
| 任务名称 | 例如“农业兴趣浏览任务” |
| 平台 | 第一阶段为 `douyin` |
| 模式 | `search`、`feed` |
| 搜索关键词 | 用于进入农业相关视频流 |
| 农业匹配关键词 | 用于判断当前内容是否农业相关 |
| 视频浏览时长 | 随机区间，例如 120-180 分钟 |
| 直播浏览时长 | 随机区间，例如 60-120 分钟 |
| 是否采集评论 | 第一阶段可开关 |
| 心跳间隔 | 默认 15 分钟 |
| 状态 | `draft`、`enabled`、`disabled` |

### 5.3 采集数据

后台展示手机脚本命中的农业候选内容。

列表字段：

| 字段 | 说明 |
|---|---|
| 采集时间 | 手机端上报时间 |
| 设备 | 来源手机 |
| 平台 | `douyin` |
| 阶段 | `video`、`live` |
| 搜索词 | 当前使用的农业搜索词 |
| 命中关键词 | 农业关键词命中结果 |
| 标题文本 | OCR 或控件识别出的标题 |
| 指标文本 | 点赞、评论、收藏等可见文本 |
| 评论摘要 | 可见热门评论摘要 |
| 原始文本 | OCR 和控件文本合并结果 |
| 原始 payload | 手机端完整上报 JSON |

### 5.4 日志中心

日志中心用于排查脚本运行问题。

需要支持：

1. 按设备筛选日志。
2. 按任务筛选日志。
3. 按日志级别筛选：`INFO`、`WARN`、`ERROR`。
4. 按停止原因筛选。
5. 查看最近一次异常前后的上下文日志。
6. 查看 15 分钟心跳记录。

### 5.5 兴趣观测看板

兴趣观测看板只做运行结果统计，不做平台标签承诺。

统计项：

| 指标 | 说明 |
|---|---|
| 今日运行时长 | 视频阶段和直播阶段分别统计 |
| 今日浏览数量 | 今日刷过的视频/直播数量 |
| 今日农业命中数量 | 命中农业关键词的候选数量 |
| 农业命中率 | 农业命中数量 / 浏览数量 |
| 搜索词覆盖 | 今日使用过哪些农业搜索词 |
| 关键词覆盖 | 今日命中过哪些农业关键词 |
| 异常次数 | 风控、验证码、权限、卡死等异常 |
| 最近停止原因 | 帮助判断是否需要人工处理 |

## 6. 数据库设计

数据库遵循部门规范：

1. 主数据库使用 PostgreSQL。
2. 表名使用 snake_case 复数形式。
3. TypeScript 属性使用 camelCase。
4. 业务表默认包含 `id`、`tenant_id`、`created_at`、`updated_at`、`created_by`、`updated_by`、`deleted_at`。
5. 当前第一阶段可以使用默认租户 `default`，但表结构必须预留 `tenant_id`。
6. JSON 字段使用 `jsonb`。
7. 时间字段使用 `timestamptz`。
8. 重要查询字段必须建立索引。

## 7. 手机端接口

接口遵循部门 REST 规范：

1. 统一使用 `/api/v1` 前缀。
2. 手机端接口和后台管理接口分开。
3. 手机端上报接口使用设备密钥或设备 token 鉴权，后台管理接口使用登录态鉴权。
4. 请求参数使用 Zod 校验。
5. 错误响应统一返回 `error.code`、`error.message`、`error.details`。

### 7.1 获取任务配置

```http
GET /api/v1/mobile/tasks/current?deviceId=android_001&platform=douyin
```

响应：

```json
{
  "taskId": "task_agri_interest_001",
  "platform": "douyin",
  "mode": "search",
  "searchKeywords": ["水稻病虫害", "玉米病虫害", "大棚蔬菜"],
  "matchKeywords": ["水稻", "玉米", "病虫害", "农药", "大棚"],
  "videoMinutesMin": 120,
  "videoMinutesMax": 180,
  "liveMinutesMin": 60,
  "liveMinutesMax": 120,
  "collectComments": true,
  "commentLimit": 10,
  "heartbeatMinutes": 15
}
```

## 8. 后台页面

### 8.1 监控看板

显示今日设备运行情况：

1. 在线设备数。
2. 正在运行设备数。
3. 今日总浏览量。
4. 今日农业命中量。
5. 今日农业命中率。
6. 今日异常次数。
7. 最近停止原因分布。

页面状态：

1. loading：指标卡和日志表格显示加载态。
2. empty：当天没有数据时显示空状态，不显示 0 以外的误导性指标。
3. error：接口失败时显示错误提示和重试按钮。

### 8.2 设备列表

每行显示一台手机，支持进入设备详情查看心跳、日志和采集记录。

筛选项：

1. 设备编号。
2. 设备状态。
3. 平台。
4. 最近心跳时间范围。

设备详情：

1. 基础信息。
2. 最近心跳。
3. 当前任务。
4. 最近 100 条运行日志。
5. 最近 100 条采集记录。

### 8.3 采集记录

支持按设备、任务、搜索词、命中关键词、时间范围筛选。

列表字段：

1. 采集时间。
2. 设备编号。
3. 阶段。
4. 搜索词。
5. 命中关键词。
6. 标题/文案。
7. 指标文本。
8. 评论摘要。

详情抽屉：

1. 原始屏幕文本。
2. 热门评论。
3. 原始 payload。
4. 关联任务和设备。

### 8.4 日志中心

支持查看运行日志、错误日志、停止原因和异常上下文。

筛选项：

1. 设备编号。
2. 任务编号。
3. 日志级别。
4. 停止原因。
5. 时间范围。

重点能力：

1. 点击一条异常日志，可以查看前后 20 条上下文日志。
2. `risk_control`、`permission_missing`、`manual_stop`、`task_finished` 用不同颜色 Tag 展示。

### 8.5 任务配置

支持维护搜索关键词、农业匹配关键词、运行时长、评论采集开关和心跳间隔。

表单规则：

1. 搜索关键词不能为空。
2. 农业匹配关键词不能为空。
3. 视频最短分钟不能小于 120。
4. 视频最长分钟不能小于视频最短分钟。
5. 直播最短分钟不能小于 60。
6. 直播最长分钟不能小于直播最短分钟。
7. 心跳间隔默认 15 分钟，不能小于 5 分钟。
8. 保存后只影响手机端下一次拉取配置，不强制中断当前运行任务。

任务状态：

| 状态 | 说明 |
|---|---|
| `DRAFT` | 草稿，不下发给手机 |
| `ENABLED` | 启用，手机端可拉取 |
| `DISABLED` | 停用，不再下发 |

## 9. 验收标准

1. 手机端可以从后台拉取任务配置。
2. 手机端可以上传采集记录，后台列表能查到。
3. 手机端每 15 分钟上传心跳，后台能显示最后心跳时间和当前状态。
4. 手机端停止或异常时，后台能看到停止原因和上下文日志。
5. 后台能统计单日运行时长、浏览数量、农业命中数量和农业命中率。
6. 后台能修改关键词和运行时长，手机端下次启动后使用新配置。
7. 后台不提供自动点赞、评论、关注、私信或给主营账号自动互动的能力。
8. 所有列表页面具备 loading、empty、error 状态。
9. 所有后台接口符合 `/api/v1`、分页响应和错误响应规范。
