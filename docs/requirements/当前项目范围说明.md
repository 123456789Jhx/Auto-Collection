# 当前项目范围说明

## 1. 当前范围

本项目当前只实现手机脚本自动化采集，不实现后台平台。

第一阶段目标：

1. 使用 AutoX.js / Auto.js 在 Android 手机上运行脚本。
2. 打开抖音并进入推荐流或搜索流。
3. 通过截图、OCR、无障碍控件读取当前视频页面信息。
4. 使用农业关键词判断是否为候选内容。
5. 命中后采集 OCR 文本、截图、可见互动指标和可见热门评论。
6. 将候选记录写入本地 JSON 缓存。
7. 如果配置了 `uploadUrl`，再把候选记录 POST 到外部 HTTP 接收端。

## 2. 当前技术栈

| 模块 | 技术 |
|---|---|
| 运行环境 | AutoX.js / Auto.js |
| 语言 | JavaScript |
| 手机能力 | 无障碍服务、悬浮窗、截图权限 |
| OCR | AutoX.js/Auto.js 可用 OCR 能力或插件 |
| 配置 | 本地 `config.js` |
| 数据存储 | 手机本地 JSON 缓存和截图文件 |
| 数据上传 | 可选 HTTP POST |
| 日志 | 手机本地日志文件 |

## 3. 当前不做

1. 不做后台管理系统。
2. 不做数据库表和服务端接口实现。
3. 不接入抖音官方 API。
4. 不做 AI 分析、审核、入素材库或知识库。
5. 不做自动点赞、评论、关注、私信。
6. 不绕过验证码、登录校验或平台风控。
7. 不批量下载完整视频。
8. 不采集非公开内容。
