# 当前项目范围说明

## 1. 当前范围

本项目当前实现手机脚本自动化采集，并增加账号数据管理平台能力。

当前核心链路是：手机脚本浏览农业相关视频和直播，提取可见文本与运行日志，账号数据管理平台接收采集结果、心跳和错误日志，用于观察设备是否正常运行、农业内容命中率是否稳定、账号内容兴趣是否持续偏向农业领域。

第一阶段目标：

1. 使用 AutoX.js / Auto.js 在 Android 手机上运行脚本。
2. 打开抖音并进入推荐流或搜索流。
3. 通过截图、OCR、无障碍控件读取当前视频页面信息。
4. 使用农业关键词判断是否为候选内容。
5. 命中后采集 OCR 文本、截图、可见互动指标和可见热门评论。
6. 将候选记录写入本地 JSON 缓存。
7. 将候选记录、运行日志、心跳状态上传到轻量后台。
8. 账号数据管理平台展示设备状态、任务进度、农业命中率、停止原因和错误日志。

## 2. 当前技术栈

| 模块 | 技术 |
|---|---|
| 运行环境 | AutoX.js / Auto.js |
| 语言 | JavaScript |
| 手机能力 | 无障碍服务、悬浮窗、截图权限 |
| OCR | AutoX.js/Auto.js 可用 OCR 能力或插件 |
| 配置 | 本地 `config.js` |
| 数据存储 | 手机本地 JSON 缓存和截图文件 |
| 数据上传 | 可选 HTTP POST |
| 日志 | 手机本地日志文件 |
| 后台服务 | Bun runtime + Hono |
| 后台数据库 | PostgreSQL |
| 后台 ORM | Drizzle ORM |
| 后台缓存 | Redis |
| 后台前端 | React 19 + Vite + Ant Design |

## 3. 当前平台范围

当前账号数据管理平台只做监控和数据接收，不做完整内容生产平台。

第一阶段后台能力：

1. 接收手机端采集到的候选视频和直播记录。
2. 接收手机端 15 分钟心跳。
3. 接收手机端运行日志、异常日志、停止原因。
4. 展示设备在线状态、当前任务、运行时长、浏览数量、采集数量。
5. 展示农业关键词命中情况、命中率、最近命中的内容样本。
6. 支持后台维护农业搜索关键词、农业匹配关键词和任务时长配置。
7. 支持手机端启动时拉取最新任务配置。
8. 支持查看单台设备的历史运行记录，排查为什么停止、卡住或进入异常页面。

## 4. 当前不做

1. 不接入抖音官方 API。
2. 不做 AI 分析、审核、入素材库或知识库。
3. 不做自动点赞、评论、关注、私信。
4. 不做给主营账号自动互动、刷互动、刷有效账户等行为。
5. 不绕过验证码、登录校验或平台风控。
6. 不批量下载完整视频。
7. 不采集非公开内容。
8. 不承诺或伪造平台对账号的标签识别结果，只记录脚本实际浏览和命中的内容证据。
