# 手机自动化脚本流程图

## 1. 流程说明

该流程描述手机端自动化脚本从启动、读取本地任务配置、打开抖音、刷视频、识别农业内容、采集评论和截图、写入本地缓存、可选上传 HTTP 接收端到结束任务的完整链路。

手机端是采集执行器，不负责最终知识判断。当前项目只实现手机脚本自动化，不实现后台管理、数据库、官方 API、AI 分析、审核和入库。

## 2. Mermaid 流程图

```mermaid
flowchart TD
    A[启动手机采集脚本] --> B{检查无障碍权限}
    B -- 未开启 --> B1[跳转无障碍设置]
    B1 --> B2[暂停并等待人工开启]
    B2 --> B
    B -- 已开启 --> C{检查悬浮窗权限}
    C -- 未开启 --> C1[跳转悬浮窗设置]
    C1 --> C2[暂停并等待人工开启]
    C2 --> C
    C -- 已开启 --> D{请求截图权限}
    D -- 失败 --> D1[记录截图权限失败]
    D1 --> Z[停止任务]
    D -- 成功 --> E[显示悬浮窗控制台]

    E --> F[读取本地 config.js 采集任务]
    F --> G{任务模式}
    G -- 搜索流 --> H[打开抖音并进入搜索]
    H --> H1[输入农业关键词]
    H1 --> H2[进入视频结果流]
    G -- 推荐流 --> I[打开抖音推荐流]

    H2 --> J[停留当前视频]
    I --> J
    J --> K[截图并执行 OCR]
    K --> L[读取可见控件文本]
    L --> M[合并 OCR 与控件文本]
    M --> N{是否农业相关}

    N -- 否 --> O[记录浏览计数]
    O --> P{达到浏览上限}
    P -- 是 --> Y[上报任务完成]
    P -- 否 --> Q[上滑下一条视频]
    Q --> J

    N -- 是 --> R[标记候选视频]
    R --> S[截取视频页证据图]
    S --> T{是否采集评论}
    T -- 否 --> W[组装上传数据]
    T -- 是 --> U[打开评论面板]
    U --> U1[OCR/控件读取热门评论]
    U1 --> U2[截取评论页证据图]
    U2 --> U3[返回视频页]
    U3 --> W

    W --> X[写入本地候选 JSON 缓存]
    X --> X0{是否启用 HTTP 上传}
    X0 -- 否 --> P
    X0 -- 是 --> X1[POST 到配置的 uploadUrl]
    X1 --> X2{上传是否成功}
    X2 -- 成功 --> X3[记录上传成功状态]
    X2 -- 失败 --> X4[保留本地缓存待补传]
    X3 --> P
    X4 --> P

    E --> E1{悬浮窗操作}
    E1 -- 暂停 --> E2[暂停自动滑动]
    E1 -- 跳过 --> Q
    E1 -- 手动采集 --> R
    E1 -- 停止 --> Z

    J --> RISK{检测到验证码/风控/登录异常}
    RISK -- 是 --> RISK1[停止自动操作并记录异常]
    RISK1 --> Z
    RISK -- 否 --> K

    Y --> Z[结束]
```

## 3. 关键状态

| 状态 | 说明 |
|---|---|
| `INIT` | 启动脚本，加载配置 |
| `PERMISSION_CHECK` | 检查无障碍、悬浮窗、截图权限 |
| `TASK_READY` | 已读取本地任务配置 |
| `OPEN_PLATFORM` | 打开抖音 |
| `ENTER_FLOW` | 进入搜索流或推荐流 |
| `WATCHING` | 当前视频停留和观察 |
| `OCR_READING` | 截图和 OCR |
| `EVALUATING` | 判断农业相关性 |
| `CAPTURING` | 采集视频页、评论页、截图证据 |
| `SAVING` | 写入本地缓存 |
| `UPLOADING` | 可选 HTTP 上传 |
| `RECOVERING` | 异常恢复 |
| `STOPPED` | 任务停止 |

## 4. 验证点

1. 每个任务必须产生开始、结束和异常日志。
2. 每次命中农业内容必须保留证据截图或 OCR 原文。
3. 任务停止后不再执行点击、滑动、评论区打开等操作。
4. 风控、验证码、登录异常出现时必须停止自动化。
5. 命中候选必须先写入本地缓存，不能依赖上传成功。
6. 上传失败必须保留本地缓存，不能静默丢弃。
