# 群控项目关系图谱

本目录已经注册为独立 Obsidian Vault，只登记项目对话和模块之间的关系，不纳入项目其他 Markdown 文档。

打开 [[00 群控项目总控]] 后，在 Obsidian 中切换到关系图谱视图，即可查看节点关系。

## 关系分层

- 根节点：[[00 群控项目总控]]
- 业务模块：[[01 视频发布]]、[[02 养号]]、[[03 更新中心]]、[[04 日志中心]]、[[05 远程唤醒]]
- 循环控制支撑：[[Agent循环控制模块]]、[[SYS 后台 API 与数据库]]
- 文档与交接：[[DOC 项目.md汇报]]、[[06 工单管理]]
- 统一前端入口：[[07 前端页面]]（planned，仅表示 Web 设计/代码依赖）
- 历史登记：`02-2 刷视频`（独立 `video` 任务，不属于当前 02 养号主线）

## 查看建议

1. 先打开 [[00 群控项目总控]]，查看完整树状关系。
2. 需要看单个模块时，在该节点页面打开局部关系图谱。
3. `07 前端页面` 是设计登记节点，不代表真实对话已创建。
4. 应在 Obsidian 中打开当前 `对话关系图谱` 目录，而不是项目根目录；项目根目录的全局图会混入其他文档。
