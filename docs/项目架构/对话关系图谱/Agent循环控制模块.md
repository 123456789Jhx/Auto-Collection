# Agent循环控制模块

负责项目内循环与外循环 Agent 的调度控制，不负责具体业务动作实现。

- 对话入口：[在 Codex 中打开](codex://threads/01a039db-fa3d-7330-b70c-911e28908ad6)

## 负责范围

- Agent 主循环、外循环和任务状态机。
- 心跳、超时、暂停、恢复、重试、退出和循环安全门禁。
- 循环运行状态上报，以及与现有任务执行入口的最小适配。

## 关系边界

- 由 [[00 群控项目总控]] 统一调度。
- 为 [[01 视频发布]]、[[02 养号]]、[[03 更新中心]]、[[04 日志中心]]、[[05 远程唤醒]] 提供循环控制支撑。
- 通过 [[SYS 后台 API 与数据库]] 对接任务状态、心跳和设备命令契约。
- 循环日志和问题事实交给 [[04 日志中心]] 整理。
- 不修改具体业务动作、前端页面、OCR、数据库 schema 或 APK 更新逻辑，除非总控明确点名文件和目标。
- 完整独立问题完成后回报总控；仅由总控决定是否触发 06 工单管理。
