## 目标和范围

本周目标是在一周内把当前可演示链路从“能跑通”推进到“可复查、可验收、可继续开发”。

本周包含：

1. 直播评论指定直播间链路回归。
2. 直播评论 STOP、状态回执、执行记录和证据补齐。
3. 手机 Agent 在线状态、命令执行状态和异常提示优化。
4. 智能发布视频最小闭环开发准备和基础接口落地。
5. GitHub 提交材料补齐：文档、截图、录屏、验收口径、日报。

本周不包含：

1. 多平台发布完整适配。
2. 发布后数据采集和效果分析。
3. AI 自动生成标题、文案、话题。
4. 绕过验证码、登录校验或平台风控。
5. 未授权的点赞、关注、私信等互动能力。

## 风险和需要确认

- 风险：直播间不在线或账号状态异常，会影响真实链路录屏。
- 风险：抖音搜索页和直播页 UI 变化，会影响目标直播间识别。
- 风险：AutoX 无障碍服务、悬浮窗、截图权限可能被系统回收。
- 风险：智能发布视频涉及平台发布页，验证码、登录校验和风控不能绕过。
- 需要确认：本周验收优先级是否为“直播评论稳定回归优先，智能发布完成基础模型和页面骨架”。
- 需要确认：正式截图和录屏是否可以使用测试直播间和测试账号。
- 需要确认：智能发布第一周是否允许先做手动创建任务，不接正式视频源接口。
