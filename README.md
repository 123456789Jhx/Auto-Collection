# Auto Collection

Auto Collection 是一个农业新媒体自动化采集与直播评论联调项目。项目由 Android 手机端 AutoX.js Agent、后台 API、后台 Web 控制台、PostgreSQL 数据库和 Redis 组成，用于小范围测试手机的抖音采集、直播观察、直播评论、设备状态监控和日志排查。

当前项目处于测试联调阶段，重点不是扩大设备规模，而是把手机脚本运行过程、后台配置、远程命令、执行记录和问题日志打通，让每台手机“正在做什么、是否在线、为什么失败、能否切换任务”可以在后台看到。

## 当前目标

1. 手机 Agent 常驻运行，完成设备注册、配置拉取、心跳上报、命令轮询和日志上传。
2. 后台集中查看设备状态、任务状态、采集记录、直播评论动作、运行日志和完整日志。
3. 后台可以保存直播评论配置，向手机下发启动、暂停、恢复、停止和刷新配置命令。
4. 手机端支持视频、直播、直播评论三个任务，并逐步增强任务切换和页面状态恢复能力。
5. 直播评论只在明确配置目标直播间和真实发送开关后执行，所有计划、跳过、失败和发送动作都需要回传审计。

## 当前能力

| 模块 | 状态 |
|---|---|
| 后台监控 | 本地联调地址 `http://localhost:3022`，线上待部署后回填 |
| 移动端 API | `http://192.168.7.170:3012/api/v1` |
| 设备注册认证 | 支持唯一设备 ID、设备 token 和 HMAC 认证 |
| 常驻心跳 | 支持手机常驻、心跳、日志、命令轮询和回执 |
| 视频采集 | 支持推荐流识别、候选记录和运行状态上报基础 |
| 直播采集 | 支持直播入口识别、停留、采样和上下文恢复基础 |
| 直播评论 | 支持账号画像、指定直播间配置、评论计划、真实发送开关和动作记录 |
| 后台 UI | 支持工作台、任务调度、直播评论、采集记录、日志中心和配置页面 |
| APK 打包 | 通过 Gradle/AutoX 打包脚本生成手机端安装包 |

## 系统结构

```text
mobile-agent/            手机端 AutoX.js 脚本和 APK 打包工程
account-data-platform/   Bun + Hono API、React Web、Drizzle 数据模型
scripts/                 打包、部署和辅助脚本
docs/                    方案设计、项目开发记录、部署、验收和证据材料
```

技术栈：

| 模块 | 技术 |
|---|---|
| 手机端 | AutoX.js / JavaScript / Android |
| 后台 API | Bun + Hono |
| 后台 Web | React 19 + Vite + Ant Design |
| 数据库 | PostgreSQL + Drizzle ORM |
| 缓存 | Redis |
| 部署 | Docker Compose |
| APK 构建 | Gradle |

## 本地运行

后台本地开发：

```powershell
cd account-data-platform
bun install
bun run db:push
bun run dev
```

默认地址：

| 服务 | 地址 |
|---|---|
| API | `http://localhost:3012` |
| Web | `http://localhost:3022` |
| 手机端 API | `http://192.168.7.170:3012/api/v1` |
| PostgreSQL | `postgres://postgres:123456@localhost:5432/auto_collection` |

手机端 APK 打包：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-autojs-apk.ps1
```

生产部署和数据清理见 [部署说明](docs/项目开发/部署说明.md)。

## 当前边界

1. 不接入抖音官方 API。
2. 不绕过验证码、登录校验、平台风控或账号安全限制。
3. 不采集非公开内容。
4. 不默认开启点赞、关注、私信等真实互动。
5. 不承诺平台推荐、账号标签或账号权重结果。
6. 完整手机脚本 ZIP 自动更新仍停用，APK 是固定基座；仅 `features/` 与 `domain/` 可通过 `biz-scripts` 通道热更新，`config.js` 永不进入更新包。

## 验收重点

1. 线上后台可打开并能查看设备、任务、日志、采集记录和直播评论数据。
2. 手机 Agent 能唯一注册设备，未注册设备访问普通移动端接口返回 401。
3. 后台保存直播评论配置后，手机端能拉取配置、执行命令并回传动作记录。
4. 视频、直播、直播评论任务切换时，手机端能逐步通过页面识别和恢复逻辑回到目标流程。
5. 日志中心能支持排查：结构化日志、完整日志、命令回执、失败原因和最近心跳可互相对账。
